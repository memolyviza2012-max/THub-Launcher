# Dying Light 2 Thai Mod - Project Tracker & Knowledge Base

## 1. โครงสร้างโฟลเดอร์ทำงาน (01-06 Structure)
เราจะใช้โครงสร้างนี้อย่างเคร่งครัดในการพัฒนาและแก้ไขม็อด:
- `01_Original_Backup/`: เก็บไฟล์ต้นฉบับดั้งเดิม (Vanilla Backup)
- `02_Translation_Workspace/`: พื้นที่สำหรับการแปลข้อความและการจัดการไฟล์ `.locres`
- `03_Font_and_UI/`: พื้นที่สำหรับจัดการฟอนต์ภาษาไทย, การตั้งค่า UI, และเครื่องมือสร้างฟอนต์
- `04_Packed_Mod/`: พื้นที่สำหรับเตรียมไฟล์ที่จะแพ็คเป็น `.pak`
- `05_Scripts_and_Tools/`: เก็บสคริปต์ Python, โปรแกรม TStudio, และเครื่องมืออื่นๆ (รวมถึงเอกสาร)
- `06_Releases/`: เก็บไฟล์ม็อดที่สำเร็จแล้วเพื่อพร้อมแจกจ่าย (เช่น `DL2_TH_V1.0_NodNuatTranslator`)

---

## 2. โครงสร้างไฟล์ Mod ของเอนจิ้นเกม (v1.0 Baseline)
เพื่อให้เอนจิ้นเกมโหลดม็อดได้สมบูรณ์ โครงสร้างการลงม็อดจะต้องเป็นไปตามนี้:
1. `ph\source\data0.pak`: ไฟล์สคริปต์ตั้งค่าเกม รวมถึงตั้งค่าหน้าต่าง UI (`.gui`, `.scr`) **ห้ามใส่ไฟล์รูปภาพลงในนี้**
2. `ph\source\data_lang\dataen.pak`: ไฟล์ข้อความที่แปลแล้ว (`.binsloc`)
3. `ph\work\data_platform\pc\assets\gui_common_pc.rpack`: แหล่งเก็บไฟล์รูปภาพฟอนต์คอมไพล์แล้ว (`.dds` / `.guivf`)

## 3. บันทึกบั๊กและการแก้ไข (Bug Log & Solutions)

### Bug 1: เกมกลายเป็นเต้าหู้ทั้งหมด (Global Tofu Bug)
- **สาเหตุ:** การพยายามยัดไฟล์ภาพฟอนต์นามสกุล `.dds` ลงไปใน `data0.pak` แถมเป็นฟอร์แมต L8 ธรรมดา ทำให้ระบบโหลดฟอนต์ของเกมชนเข้ากับไฟล์ `gui_common_pc.rpack` เดิม และแครชทั้งระบบ เนื่องจากเกมบังคับให้ใช้รูปแบบภาพ `DX10 BC7_UNORM` สำหรับ UI เท่านั้น
- **วิธีแก้:** หยุดการยัด `.dds` ลงใน `data0.pak` โดยให้จัดการรูปภาพผ่าน `gui_common_pc.rpack` แทน

### Bug 2: คำว่า "คุณตายแล้ว" กลายเป็นเต้าหู้แดง 5 ก้อน (Death Screen Bug)
- **สาเหตุ:** ตัวละครภาษาไทยของคำนี้ถูกแปลงเป็นรหัส PUA เพื่อแก้สระลอย แต่หน้าต่าง `deathscreen_widget_pc.gui` และ `gui_presets.scr` มีคำสั่ง `"Uppercase": "1"` (บังคับพิมพ์ใหญ่) การบังคับพิมพ์ใหญ่ใส่รหัส PUA ทำให้รหัสพัง และโชว์เป็นเต้าหู้
- **วิธีแก้:** แกะ `data0.pak` ของ v1.0 ออกมา แก้ไขบรรทัด `"Uppercase"` ให้เป็น `"0"` แล้วแพ็คกลับด้วยการบีบอัดแบบเดิม (Deflated)

## 4. กฎเหล็กของโปรเจกต์ (Project Rules)
1. ห้ามสร้างไฟล์/โฟลเดอร์ขยะนอกพื้นที่ 01-06 ใน `DL2_mod_workspace` เด็ดขาด
2. ใช้ v1.0 ใน `06_Releases` เป็น Baseline ในการทำงานเสมอ
3. หากได้ความรู้เชิงโครงสร้างใหม่ๆ เพิ่มเติม จะต้องซิงก์ข้อมูลไปที่ `Modding-Knowledge\Games\Dying Light 2` ตามกฎ Global Rule ด้วย
