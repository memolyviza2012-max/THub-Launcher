## บทนำ: ทำความเข้าใจระบบฟอนต์ของ C-Engine

Dying Light 2 ใช้เอนจิ้นชื่อ **C-Engine** ซึ่งมีระบบฟอนต์แบบ **Bitmap Font Atlas** — ไม่ใช่ Vector Font หมายความว่า:
- แต่ละขนาด (Size) และแต่ละ Style (Bold, Light, Regular ฯลฯ) ต้องมีไฟล์แผนที่ตัวอักษรของตัวเองแยกต่างหาก
- ถ้าเกมต้องการ FontSize ที่ไม่มีไฟล์ → ตัวอักษรจะกลายเป็น **เต้าหู้ (Tofu/□□□)**

---

## ภาพรวมระบบฟอนต์ (Architecture)

```
[GUI File (.gui)] 
    └─ กำหนด FontSize, FontStyle, FontFamily
           │
           ▼
[gui_presets.scr]  ← มี Preset ชื่อ เช่น "H8" กำหนด FontFamily/Style ไว้
           │
           ▼
[Font Script (.scr)] ← ไฟล์หลัก: จับคู่ Unicode → พิกัดบน Texture Atlas
   เช่น: gui/common_pc/din_pro_bold_36_pc.scr
           │
           ▼
[Texture Atlas (.dds)] ← ภาพที่เก็บ Bitmap ของตัวอักษรทั้งหมด
   เช่น: common_fonts_0_PC_uif.dds  (อยู่เป็น Loose File)
```

## โครงสร้างไฟล์ Font Script (.scr)

```c
// WARNING: this file is auto generated by GuiEditor. Do not modify by hand!

sub main()
{
    TTF("DINPro-CondBold.otf");      // ชื่อ Font file จริง (ไม่ต้องมี)
    
    Size(36); //[points]             // ขนาด ต้องตรงกับชื่อไฟล์!
    Ascender(30.000);                // ความสูงเหนือ baseline
    Descender(-9.000);               // ความลึกใต้ baseline
    LineSpace(39.000);               // ระยะห่างระหว่างบรรทัด
    
    Texture("common_fonts_0_PC_uif.dds")  // Texture Atlas หลัก (index 0)
    Texture("common_fonts_1_PC_uif.dds")  // Atlas เพิ่มเติม (index 1)
    ...
    
    // รูปแบบ: Char(unicode, bmp_w, bmp_h, atlas_x, atlas_y, off_x, off_y, adv_x, adv_y)
    Char(32, 0, 0, 0, 0, 0, 0, 9.0000, 0);        // Space
    Char(3585, 38, 35, 2689, 1163, 0, -35, 39.0000, 0);  // ก (Thai)
    ...
}
```

### ฟิลด์ใน Char():
| ฟิลด์ | ความหมาย |
|-------|----------|
| `unicode` | รหัส Unicode ทศนิยม เช่น 3585 = U+0E01 = ก |
| `bmp_w`, `bmp_h` | ขนาด Bitmap ของตัวอักษรนั้น (pixels) |
| `atlas_x`, `atlas_y` | ตำแหน่ง X, Y บน Texture Atlas |
| `off_x`, `off_y` | Offset จาก baseline (off_y มักเป็นลบ = ขึ้นบน) |
| `adv_x`, `adv_y` | Advance (ระยะเดินต่อ) ปกติ adv_y = 0 |

### การคำนวณ Texture Index จาก atlas_y:
```python
texture_index = atlas_y // texture_height  # (texture_height ปกติ = 4096)
y_in_texture  = atlas_y % texture_height
```
ถ้า `texture_index >= จำนวน Texture()` ที่ระบุไว้ → **เต้าหู้!**

## ขั้นตอนการเพิ่มภาษาไทยให้ทำงานได้

### ขั้นที่ 1: สร้าง Texture Atlas ใหม่

ต้องสร้างไฟล์ DDS ที่มีตัวอักษรไทยครบทุกตัว:

```python
# ตัวอย่างการสร้าง Atlas ด้วย Python + Pillow
from PIL import Image, ImageDraw, ImageFont

atlas = Image.new('RGBA', (4096, 4096), (0, 0, 0, 0))
draw = ImageDraw.Draw(atlas)
font = ImageFont.truetype('Kanit-Bold.ttf', 36)

# วาดตัวอักษรไทยทุกตัว แล้วจดพิกัดไว้
char_map = {}
x, y = 0, 0
for codepoint in range(0x0E00, 0x0E7F):
    char = chr(codepoint)
    bbox = draw.textbbox((x, y), char, font=font)
    draw.text((x, y), char, font=font, fill='white')
    char_map[codepoint] = (x, y, bbox[2]-bbox[0], bbox[3]-bbox[1])
    x += (bbox[2]-bbox[0]) + 2
    if x > 4000:
        x = 0
        y += 40

atlas.save('kanit_thai_atlas.png')
# แปลงเป็น DDS ด้วย texconv หรือ GIMP
```

**รูปแบบ DDS ที่ถูกต้อง:** `BC3 (DXT5)` หรือ `A8R8G8B8`

### ขั้นที่ 3: แก้ไข Font Script (.scr) ใน data0.pak

สร้าง .scr ที่มีพิกัดตัวอักษรไทยถูกต้อง:

```python
import zipfile, shutil, os

pak_path = r'F:\SteamLibrary\steamapps\common\Dying Light 2\ph\source\data0.pak'
temp_pak = r'E:\Mod_Workspace\data0_new.pak'

# patch_data = dict ของ {filename: new_content_bytes}
patch_data = {
    'gui/common_pc/din_pro_bold_36_pc.scr': new_scr_content.encode('utf-8'),
    # ... ใส่ทุกขนาดและ Style ที่ต้องการแก้
}

# ⚠️ ต้อง REBUILD เท่านั้น ห้าม APPEND!
seen = set()
with zipfile.ZipFile(pak_path, 'r') as zin, \
     zipfile.ZipFile(temp_pak, 'w', zipfile.ZIP_DEFLATED) as zout:
    for item in zin.infolist():
        n = item.filename
        if n in seen:
            continue  # ข้ามไฟล์ซ้ำ
        seen.add(n)
        if n in patch_data:
            zout.writestr(item, patch_data[n])
        else:
            zout.writestr(item, zin.read(n))

shutil.copy2(temp_pak, pak_path)
os.remove(temp_pak)
```

### ขั้นที่ 4: แก้ GUI Widget Files สำหรับ FontSize ที่ไม่มี .scr

หาก GUI ใช้ FontSize ที่ไม่มี .scr รองรับ (เช่น 21, 27, 96) → Remap ให้ใช้ขนาดที่ใกล้เคียงที่มีอยู่:

```python
import re

available_sizes = [10, 16, 36]  # ขนาดที่มี .scr ใน 1.0.2

def remap_size(size_int):
    if size_int <= 13:
        return 10
    elif size_int <= 26:
        return 16
    else:
        return 36

def patch_gui_fontsizes(content):
    def replacer(m):
        val = float(m.group(1))
        size_int = int(val)
        if size_int in available_sizes:
            return m.group(0)
        new_size = remap_size(size_int)
        return 'FontSize": "' + str(new_size) + '.000000'
    return re.sub(r'FontSize":\s*"([\d.]+)', replacer, content)
```

**เหตุผล:** C-Engine อ่าน **entry แรก** ในไฟล์ ZIP เสมอ ไม่ใช่ entry ล่าสุด!
ถ้า Append → มี entry ซ้ำ 2 อัน → เกมโหลดตัวเก่า → แก้ไขไม่มีผล

### ❌ กฎ 2: C-Engine ย่อ/ขยายรูปฟอนต์ด้วยตัวเองไม่ได้! (The Bulk Remap Rule)
**ห้าม** เขียนสคริปต์หลอกเอนจิ้นด้วยการทำไฟล์ไซส์ 18 แต่ไปใช้รูปภาพไซส์ 36 เด็ดขาด! 
- เอนจิ้นจะดึงรูปขนาด 36 มาแปะ แต่เว้นระยะเคอร์เซอร์แค่ 18 ทำให้ตัวหนังสือซ้อนทับกันเละเทะ
- **วิธีแก้เดียวที่ถูกต้อง:** ถ้ารูปวาดไว้แค่ขนาด 10, 16, 36 **ต้องบังคับให้ทั้งเกมใช้แค่ 10, 16, 36 เท่านั้น**
- **วิธีทำ:** ใช้ Python สแกนกวาดล้างไฟล์ `.gui` ทั้งหมด (เกือบพันไฟล์) และไฟล์ `gui/gui_presets.scr` แล้วสั่ง Remap ไซส์แปลกๆ (เช่น 21, 66) ให้ถูกปัดลงมาหา 10, 16 หรือ 36

## วิธี Scale .scr จากขนาดที่มีอยู่ไปขนาดใหม่

หากต้องการเพิ่มขนาดใหม่ (เช่น 96 จาก 36):

```python
import re

def scale_font_script(src_file, dst_file, target_size, base_size=36.0):
    scale = target_size / base_size
    
    with open(src_file, 'r', encoding='utf-8', errors='ignore') as f:
        lines = f.readlines()
    
    with open(dst_file, 'w', encoding='utf-8') as f:
        for line in lines:
            stripped = line.strip()
            
            if stripped.startswith('Size('):
                f.write(f'    Size({target_size}); //[points]\n')
            
            elif stripped.startswith('Ascender('):
                val = float(re.search(r'Ascender\((.*?)\)', line).group(1))
                f.write(f'    Ascender({val * scale:.3f});\n')
            
            elif stripped.startswith('Descender('):
                val = float(re.search(r'Descender\((.*?)\)', line).group(1))
                f.write(f'    Descender({val * scale:.3f});\n')
            
            elif stripped.startswith('LineSpace('):
                val = float(re.search(r'LineSpace\((.*?)\)', line).group(1))
                f.write(f'    LineSpace({val * scale:.3f});\n')
            
            elif stripped.startswith('Char('):
                # Char(unicode, bw, bh, atlas_x, atlas_y, off_x, off_y, adv_x, adv_y)
                parts = re.findall(r'Char\((.*?)\)', line)[0].split(',')
                if len(parts) >= 9:
                    # ⚠️ atlas_x, atlas_y ไม่ต้อง scale (ตำแหน่งบน texture คงที่)
                    # ที่ต้อง scale: off_x, off_y, adv_x, adv_y
                    off_x = float(parts[5].strip())
                    off_y = float(parts[6].strip())
                    adv_x = float(parts[7].strip())
                    adv_y = float(parts[8].strip())
                    
                    parts[5] = f"{off_x * scale:.1f}"
                    parts[6] = f"{off_y * scale:.1f}"
                    parts[7] = f"{adv_x * scale:.4f}"
                    parts[8] = f"{adv_y * scale:.4f}"
                    
                    f.write(f'Char({", ".join(parts)});\n')
                else:
                    f.write(line)
            else:
                f.write(line)

# ตัวอย่างการใช้งาน:
# scale_font_script('din_pro_bold_36_pc.scr', 'din_pro_bold_96_pc.scr', 96, base_size=36)
```

> ⚠️ **ข้อควรระวัง:** ไฟล์ต้นฉบับที่ใช้ Scale ต้องเป็นไฟล์ที่ **ดึงออกมาจากเกมโดยตรง** (ไม่ใช่ไฟล์ที่เราแก้ไขเองไว้ก่อนหน้า) เพราะอาจมีพิกัดผิด

## ตรวจสอบว่า Patch ทำงานจริงหรือไม่

```python
import zipfile
from collections import Counter

pak_path = r'F:\SteamLibrary\steamapps\common\Dying Light 2\ph\source\data0.pak'

with zipfile.ZipFile(pak_path, 'r') as z:
    names = z.namelist()
    dup_count = Counter(names)
    dups = [(n, c) for n, c in dup_count.items() if c > 1]
    
    print(f'Total entries: {len(names)}')
    print(f'Duplicate entries: {len(dups)}')  # ต้องเป็น 0!
    
    if dups:
        print('⚠️ WARNING: Duplicates found! Game will NOT load patched files!')
        for n, c in dups[:10]:
            print(f'  {n} ({c} times)')
```
