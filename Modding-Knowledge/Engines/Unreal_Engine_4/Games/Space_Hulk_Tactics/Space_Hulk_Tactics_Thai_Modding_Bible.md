# 📚 Knowledge Item (KI): คัมภีร์การทำม็อดภาษาไทยเกม Space Hulk: Tactics

**ชื่อเกม:** Space Hulk: Tactics
**เอนจิ้น (Engine):** Unreal Engine 4 (รุ่นเก่า, ไฟล์ Pak รูปแบบ Legacy V3)
**ผู้สร้าง (Modder):** หน๊ด หนวด translator

---

## 📌 สรุปปัญหาหลักที่พบในการแปลเกมนี้
ในการทำม็อดภาษาไทยสำหรับเกม Space Hulk: Tactics เราพบอุปสรรคสำคัญ 3 ประการ:
1. **เกมไม่รองรับโฟลเดอร์ `~mods`:** เอนจิ้น UE4 รุ่นเก่าของเกมนี้ยังไม่มีการเปิดใช้ระบบโฟลเดอร์ `~mods` ทำให้ต้องใช้ระบบ Patching โดยการเติม `_P` ต่อท้ายชื่อไฟล์ `.pak`
2. **เครื่องหมายสัญลักษณ์ (UI Icons) ฝังอยู่ในฟอนต์เดิม:** การพยายามนำฟอนต์ภาษาไทยไปเขียนทับ (Replace) ฟอนต์เดิมของเกม (เช่น `Exo` หรือ `Roboto`) ทำให้สัญลักษณ์ UI ของเกม (เช่น ไอคอน Action Points รูปร่างสี่เหลี่ยมข้าวหลามตัด หรือไอคอนจอยสติ๊ก) หายไปและกลายเป็นสี่เหลี่ยมเพชร
3. **การหลอนของ AI (Hallucination):** การใช้เครื่องมือแปลภาษาอัตโนมัติ ทำให้เกิดข้อความขยะ แท็กเกิน หรือแต่งประโยคใหม่เอง ซึ่งสร้างปัญหา UI ล้นกรอบ

---

## 🛠️ วิธีการแก้ไขและการปรับแต่ง (The Solutions)

### 1. โครงสร้างไฟล์แปลภาษา (Localization)
คำแปลของเกมถูกแยกออกเป็น 2 ไฟล์หลักในสกุล `.locres`:
- `Game.locres` (ข้อความ UI และเมนูทั่วไป) -> Path: `SpaceHulk2\Content\Localization\Game\en`
- `Dialogues.locres` (ข้อความบทสนทนาและซับไตเติล) -> Path: `SpaceHulk2\Content\Localization\Dialogues\en`
ทำการดึงไฟล์ออกเป็น CSV ผ่าน TStudio, ทำการแปล, และแปลงกลับเป็น `locres`

### 2. เทคนิคการจัดการฟอนต์ (Slate Font Fallback Trick)
**นี่คือหัวใจสำคัญของการทำฟอนต์เกมนี้!** เพื่อรักษาไอคอน UI เดิมของเกมไว้ 100% เราจะไม่ไปแตะต้องฟอนต์ในโฟลเดอร์ `UI\fonts` ของเกมเลย แต่เราจะใช้ฟีเจอร์ฉุกเฉินของ Unreal Engine:
1. นำฟอนต์ภาษาไทย (เช่น IBM Plex Sans ที่ปรับแก้สระลอยแล้ว) มาเปลี่ยนชื่อเป็น **`DroidSansFallback.ttf`**
2. นำไปวางในโครงสร้าง: `Engine\Content\Slate\Fonts\DroidSansFallback.ttf`
3. **หลักการ:** เกมจะใช้ฟอนต์เดิมแสดงภาษาอังกฤษและไอคอน แต่เมื่อเจอตัวอักษรไทยที่ฟอนต์เดิมไม่มี เกมจะดึง `DroidSansFallback.ttf` ของเรามาแสดงแทนแบบไร้รอยต่อ

### 3. การแพ็คไฟล์ (Packing)
1. รวมไฟล์ `locres` ที่แปลแล้ว และไฟล์ `DroidSansFallback.ttf` เข้าด้วยกันในโฟลเดอร์ Staging
2. ใช้เครื่องมือ **UnrealPak** ในการบีบอัดไฟล์ 
3. **สำคัญมาก:** ตั้งชื่อไฟล์แพ็คเกจให้ลงท้ายด้วย `_P.pak` เช่น `pakchunk99-WindowsNoEditor_P.pak`
4. นำไฟล์ `.pak` นี้ไปวางทับในโฟลเดอร์ `SpaceHulk2\Content\Paks` โดยตรง (ไม่ต้องสร้างโฟลเดอร์ `~mods`)

## 📋 ข้อควรระวัง
- หมั่นตรวจสอบ AI Hallucination ในไฟล์ CSV หากพบแท็กประหลาดหรือคำแปลยาวผิดปกติ ให้รีบแก้ไขก่อนแปลงไฟล์เป็น `locres` มิฉะนั้น UI จะล้นหรือเกมอาจแสดงผลผิดพลาด
- การแปลคำศัพท์เฉพาะ (Lore) ของ Warhammer 40k ควรศึกษาบริบทให้ดีก่อนเสมอ
