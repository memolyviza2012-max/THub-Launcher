# 🛠️ สรุปการไขปริศนา "ฟอนต์ล่องหน" ขั้นสุดยอด ตอนที่ 6 (The Pridi Update)

หลังจากที่เราเอาชนะระบบ Engine ได้สำเร็จด้วยการใช้เทคนิค "สวมรอยชื่อฟอนต์ (Internal Name Patching)" ไปแล้ว 
การเปลี่ยนไปใช้ฟอนต์ **Pridi (ปรีดี)** ตามที่คุณต้องการก็กลายเป็นเรื่องง่ายเหมือนปอกกล้วยเข้าปากครับ!

## ✅ สรุปขั้นตอนการเปลี่ยนฟอนต์เป็น Pridi
1. ผมทำการตรวจสอบฟอนต์ `Pridi-Regular_PUA.ttf` และพบว่ามันมีค่า **UPM = 1000** ซึ่งมีโครงสร้างขนาด (Metric) เท่ากับ Kanit และฟอนต์ดั้งเดิมของเกมเป๊ะๆ!
2. นี่คือข่าวดีสุดๆ เพราะเราสามารถใช้สคริปต์สวมรอยตัวเดิมได้เลย!
3. ผมนำสคริปต์มารันเพื่อถอดเอา Name Table ออริจินัลของเกมมายัดใส่ `Pridi` 
4. ทำการบันทึกทับฟอนต์ทั้ง 17 ไฟล์ (Cinzel, EBGaramond, Noto) และแพ็คลงในไฟล์ Mod ให้คุณเรียบร้อยครับ

---
คุณสามารถเข้าเกมเพื่อทดสอบฟอนต์ใหม่ **"Pridi"** ได้เลยครับ คราวนี้ฟอนต์จะถูกเปลี่ยนทั้งระบบหน้าจอ UI ทันที! ขอให้สนุกกับการเล่นเกม Expeditions: Rome นะครับ! 🚀
