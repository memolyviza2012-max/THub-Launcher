# 📖 คัมภีร์การสร้าง Mod ภาษาไทย: Marvel's Guardians of the Galaxy

คัมภีร์ฉบับนี้รวบรวมเทคนิค กระบวนการ และโค้ดทั้งหมดที่ใช้ในการสร้าง Mod แปลภาษาไทยสำหรับเกม **Marvel's Guardians of the Galaxy (Dawn Engine)** ตั้งแต่ศูนย์จนจบกระบวนการ เพื่อเป็นฐานความรู้ (Knowledge Base) สำหรับพัฒนา Mod หรือประยุกต์ใช้กับเกมอื่นๆ ที่ใช้เอนจิ้นใกล้เคียงกัน

---

## 1. 🔍 วิเคราะห์โครงสร้างและเอนจิ้นเกม (Dawn Engine)
เกมนี้พัฒนาโดยใช้ **Dawn Engine** (เอนจิ้นเดียวกับ Deus Ex: Mankind Divided) ซึ่งมีพฤติกรรมหลักๆ ดังนี้:
- **String Rendering:** เกมเก็บข้อความ (Strings) ในรูปแบบ Hash-based Dictionary โดนโยงกับไฟล์ `.bin` หรือ `.drm` ภายใน
- **Font Rendering:** เกมใช้ไลบรารี **FreeType (FT)** ในการวาดตัวอักษร โดยอ่านไฟล์ TTF/OTF จาก Memory โดยตรง 
- **Modding Approach:** เราไม่สามารถแก้ไขไฟล์แปลของเกมได้โดยตรงเพราะถูกเข้ารหัสและบีบอัดอย่างซับซ้อน เราจึงต้องใช้เทคนิค **DLL Injection & Function Hooking (ผ่าน MinHook)** เพื่อดักจับข้อความภาษาอังกฤษแบบ Real-time และสลับเป็นภาษาไทยก่อนที่มันจะถูกส่งไปวาดบนหน้าจอ

---

## 2. 🛠️ โครงสร้างของโปรเจค (C++ DLL)
โปรเจคของเราถูกสร้างเป็นไฟล์ `version.dll` (Proxy DLL) เพื่อให้เกมโหลดไฟล์นี้เข้าไปโดยอัตโนมัติเมื่อเริ่มเกม โดยมีการแบ่งการทำงานหลักๆ ดังนี้:

### 2.1. Proxy DLL (`DllMain.cpp`)
ทำหน้าที่ปลอมตัวเป็น `version.dll` ของระบบ Windows เพื่อให้เกมโหลด Mod ของเราเข้าไปก่อน จากนั้นเราจะโยนการทำงานดั้งเดิมกลับไปหา `C:\Windows\System32\version.dll` และเริ่มการทำงานของ Mod ใน Async Thread เพื่อไม่ให้เกมค้างตอนเปิด

### 2.2. Pattern Scanning (`PatternScanner.cpp`)
เนื่องจากเกมมีการอัปเดตหลายเวอร์ชั่น (Steam, Epic, Game Pass) Address ของฟังก์ชั่นใน Memory จึงไม่ตายตัว เราจึงต้องใช้ระบบ "สแกนหาแพทเทิร์นของ Bytecode" (Pattern Scanning) เพื่อหาตำแหน่งของฟังก์ชั่นที่เราต้องการ Hook ในแรม เช่น:
- `FT_New_Memory_Face` (ฟังก์ชั่นโหลดฟอนต์)
- `GetText` / `TryGetText` (ฟังก์ชั่นดึงข้อความมาแสดง)
- `OnSetText` (ซับไตเติ้ล)

## 3. 🪝 การทำ Hooking ด้วย MinHook (`TranslationHooks.cpp`)
นี่คือหัวใจหลักของการแปลภาษา เราใช้ไลบรารี MinHook ดักจับฟังก์ชั่นของเกม และเขียนฟังก์ชั่นของเราไปคั่นกลาง (Detour)

### 3.1. ดักจับข้อความ (Text Hooking)
เราทำการ Hook ฟังก์ชั่นจำพวก `GetText` เมื่อเกมขอข้อความภาษาอังกฤษ เช่น "Start Game" ฟังก์ชั่นของเราจะทำงาน:
1. รับข้อความภาษาอังกฤษมา
2. ค้นหาในไฟล์ `strings_th.json` (ที่เราโหลดเตรียมไว้บน RAM ด้วย nlohmann::json)
3. ถ้าเจอคำแปลไทย (เช่น "เริ่มเกม") เราจะส่งคำแปลไทยกลับไปให้เกมวาดแทนภาษาอังกฤษ
4. ถ้าไม่เจอ ก็ส่งภาษาอังกฤษกลับไปตามปกติ

### 3.2. สลับฟอนต์ (Font Swapping)
ปัญหาใหญ่ของการทำ Mod ภาษาไทยคือ "ตัวอักษรเป็นสี่เหลี่ยม (Tofu)" เพราะฟอนต์ดั้งเดิมของเกมไม่มีสระและพยัญชนะไทย เราแก้ปัญหานี้โดยการ Hook ฟังก์ชั่น `FT_New_Memory_Face` ของ FreeType:
- เมื่อเกมพยายามโหลดฟอนต์ UI ภาษาอังกฤษ (ขนาดไฟล์ประมาน `404856` ไบต์ หรือ `241940` ไบต์)
- เราจะสั่ง **"สลับ Memory Buffer"** โดยโยนไฟล์ `font_th.ttf` (ฟอนต์ไทยที่เราเตรียมไว้) เข้าไปแทนที่!
- FreeType จะอ่านฟอนต์ไทยของเราและสามารถวาดสระ/วรรณยุกต์ไทยบนหน้าจอได้สมบูรณ์แบบ

## 4. 🗂️ โครงสร้างไฟล์สำหรับแจกจ่าย (Release)
ผู้เล่นเพียงแค่ต้องนำไฟล์เหล่านี้ไปวางในโฟลเดอร์เกม (ที่เดียวกับ `gotg.exe` ซึ่งมักจะเป็นโฟลเดอร์ `bin` หรือ `retail`)
1. **`version.dll`** - ตัวแฮกและแทรกแซงเกม (Mod Core)
2. **`font_th.ttf`** - ไฟล์ฟอนต์ภาษาไทย (เช่น Noto Sans Thai หรือฟอนต์ที่บอสดีไซน์)
3. **`strings_th.json`** - ไฟล์ฐานข้อมูลคำแปล (Dictionary)
4. **`GOTG_Mod.ini`** - ไฟล์ตั้งค่าของ Mod (สามารถเปิด-ปิด Mod หรือเปิดโหมด Debug ได้จากไฟล์นี้)

## 5. 🚨 ปัญหาที่เคยพบ (Troubleshooting & Known Issues)

### 5.1. อาการ: เกมเด้งหลังจากเล่นไปได้ 5 นาที (I/O Bottleneck)
- **สาเหตุ:** ในเวอร์ชั่นพัฒนา เราเปิดระบบ Debug Logging (`Debug=1`) ไว้ ซึ่งตัว Mod จะเขียน Log ลงฮาร์ดดิสก์ทุกครั้งที่มีการเรนเดอร์ข้อความ (หลายร้อยครั้งต่อวินาที) ทำให้ฮาร์ดดิสก์โหลดไม่ทัน (I/O Bottleneck) และทำให้ Memory ของเกมค้างจนเด้งออก
- **วิธีแก้:** ต้องแน่ใจว่าในไฟล์ `GOTG_Mod.ini` ที่ส่งให้ผู้เล่น ถูกตั้งค่าเป็น **`Debug=0`** (ปิดการเขียน Log อย่างเด็ดขาด) ตัวเกมจะลื่นและเสถียร 100%

### 5.2. อาการ: เกมเด้งตั้งแต่ตอนแรก (เด้งหน้า Launcher)
- **สาเหตุ:** ผู้เล่นในระบบ Steam เมื่อกดเข้าเกม มันจะเปิดหน้าจอ "Launcher" เล็กๆ ขึ้นมาก่อน ซึ่งหน้าต่าง Launcher นี้ไม่ใช่ Dawn Engine แต่ DLL ของเราพยายามไปเจาะระบบ Memory ของมัน ทำให้ Launcher พังและเด้งปิดทันที
- **วิธีแก้:** ต้องบอกให้ผู้เล่นไปที่ Steam -> คลิกขวาที่เกม -> Properties -> Launch Options -> พิมพ์คำว่า **`-nolauncher`** เพื่อข้ามหน้าต่าง Launcher และเข้าสู่เกมโดยตรง

### 5.3. อาการ: สระลอยหรือฟอนต์ทับกัน
- **สาเหตุ:** เกิดจากการออกแบบของไฟล์ TTF ดั้งเดิม
- **วิธีแก้:** ต้องใช้เครื่องมือสร้างฟอนต์อย่าง FontForge ในการปรับแก้ Kerning หรือใช้โค้ด C++ ตรวจจับสระบน/ล่าง (เช่น ไม้โท, สระอิ) เพื่อปรับระยะแกน Y แบบ Real-time ก่อนส่งให้ FreeType วาด
