--- Font Effect System ---
  fontfxglowparms       — Glow effect parameters
  fontfxglowcolor       — Glow color
  fontfxoutlinecolor    — Outline color
  fontfxparms           — General font effect parameters
  fontoutlineglowshadow — Shadow + outline shader
  worldtextfont         — 3D world text font

--- Font Structure (per font) ---
  fonts/{name}/
    64_df.tga       — SDF font atlas image (Distance Field)
    64_df.dat       — Glyph metrics (character positions, kerning, sizes)
    64_df.tga.decl  — Material declaration (tells engine how to load)

--- Storage ---

  Font metrics (DAT):      rsc_gen_0_0.resources (381 MB, Oodle compressed)
  Declarations (DECL):     rsc_decl_0.resources (28.7 MB, plaintext)

--- IMPORTANT ---
  All font data (TGA/DAT) is inside Oodle-compressed .resources files.
