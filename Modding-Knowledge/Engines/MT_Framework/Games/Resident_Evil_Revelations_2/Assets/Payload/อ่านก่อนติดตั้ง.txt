==========================================================
  Resident Evil Revelations 2 - ม็อดภาษาไทย  v1.0   (by Lung Dear)
  ตัวติดตั้งแบบ .bat
==========================================================

ไม่ต้องลงโปรแกรมเพิ่ม ใช้ Command Prompt ที่มากับ Windows

** แตก zip ออกมาก่อน อย่าเปิดจากในไฟล์ zip โดยตรง **
** Install_ThaiMod.bat กับโฟลเดอร์ mod ต้องอยู่ข้างกันเสมอ **


----------------------------------------------------------
 ม็อดนี้มีอะไรบ้าง
----------------------------------------------------------
 - แปลด้วยมือทั้งเกม 5,886 ข้อความ ไม่ใช้เครื่องแปลภาษา
   แคมเปญทุกตอน, Raid Mode, เมนู, ไอเทม, เอกสาร, ซับไตเติล,
   ทิปและคำคมหน้าโหลด
 - ฟอนต์ไทย Sarabun ทุกขนาดที่เกมใช้ วางสระ-วรรณยุกต์ไม่ซ้อนกัน
   รวมถึงหัวข้อจอและหน้าโหลดที่เกมจัดช่องไฟเอง


----------------------------------------------------------
 วิธีติดตั้ง
----------------------------------------------------------
 1. ปิดเกมก่อน
 2. แตก zip ไว้ที่ไหนก็ได้
 3. ดับเบิลคลิก Install_ThaiMod.bat
    Windows จะถามสิทธิ์ผู้ดูแลระบบ ให้กด "ใช่"
 4. หน้าต่างสีดำจะขึ้นมา (ข้อความในหน้าต่างเป็นภาษาอังกฤษ)
    ดูบรรทัด  Game folder :  ว่าเจอโฟลเดอร์เกมแล้ว
      - ถ้าขึ้น NOT FOUND ให้พิมพ์ 3 กด Enter
        แล้ววางที่อยู่โฟลเดอร์เกมที่มีไฟล์ rerev2.exe
        (Steam: คลิกขวาที่เกม > Manage > Browse local files
         แล้วก๊อปที่อยู่จากแถบด้านบนของหน้าต่าง)
 5. พิมพ์ 1 แล้วกด Enter เพื่อติดตั้ง รอประมาณ 10-30 วินาที
 6. ขึ้นว่า Done แล้ว เปิดเกมได้เลย

 ในเกมให้ตั้งภาษาเป็น English - ม็อดนี้ใส่ภาษาไทยไว้ในช่องภาษาอังกฤษ

 เมนูในหน้าต่าง
   1. Install Thai mod                    ติดตั้งม็อดภาษาไทย
   2. Uninstall (restore English files)   ถอนการติดตั้ง กลับเป็นอังกฤษ
   3. Change game folder                  เปลี่ยนโฟลเดอร์เกม
   4. Exit                                ออก

 DLC ตอนไหนไม่มีในเครื่อง ตัวติดตั้งจะข้ามให้เอง


----------------------------------------------------------
 วิธีถอนการติดตั้ง (กลับเป็นภาษาอังกฤษ)
----------------------------------------------------------
 ดับเบิลคลิก Install_ThaiMod.bat อีกครั้ง พิมพ์ 2 แล้วกด Enter

 ตอนติดตั้ง ไฟล์ต้นฉบับจะถูกสำรองไว้ในโฟลเดอร์เกมที่
     _ThaiMod_Backup_Original      (ประมาณ 100 MB)
 อย่าลบโฟลเดอร์นี้ ถ้ายังอยากถอนการติดตั้งได้ในภายหลัง
 ถอนเสร็จแล้วโฟลเดอร์นี้จะถูกลบให้เอง

 อีกวิธี: Steam > คลิกขวาที่เกม > Properties > Installed Files >
          Verify integrity of game files


----------------------------------------------------------
 ม็อดแตะไฟล์อะไรบ้าง
----------------------------------------------------------
 แทนที่ไฟล์ของเกมเฉพาะที่มีข้อความและฟอนต์เท่านั้น
   nativePCNext\arc\          82 ไฟล์
   nativePCNext\ui_N\00_font\ ฟอนต์ 11 ไฟล์
   nativePCNext\message\win\  ข้อความ 227 ไฟล์
   dat\DLC_EPISODE_...\       28 ไฟล์ (เฉพาะตอนที่มีในเครื่อง)

 - ไม่แก้ rerev2.exe  ไม่แตะเซฟเกม  ไม่ติดตั้งอะไรลง Windows
 - Install_ThaiMod.bat เปิดอ่านด้วย Notepad ได้ทุกบรรทัด
 - ประวัติการติดตั้งถูกบันทึกไว้ที่ install_log.txt ข้าง ๆ ไฟล์ .bat


----------------------------------------------------------
 คำถามที่พบบ่อย
----------------------------------------------------------
 ถาม: ดับเบิลคลิกแล้วหน้าต่างขึ้นแป๊บเดียวแล้วหาย
 ตอบ: - เช็กว่าแตก zip ออกมาแล้ว ไม่ได้เปิดจากในไฟล์ zip
      - ตอนที่ Windows ถามสิทธิ์ ต้องกด "ใช่"

 ถาม: Windows ขึ้นว่า "Windows protected your PC"
 ตอบ: กด More info > Run anyway  (เกิดกับไฟล์ที่ดาวน์โหลดจากอินเทอร์เน็ต)

 ถาม: ขึ้นว่า ERRORS หลังติดตั้ง
 ตอบ: ปิดเกมให้หมด แล้วรัน Install_ThaiMod.bat ใหม่ กดใช่ตอนถามสิทธิ์
      ถ้ายังไม่หาย ดูรายชื่อไฟล์ที่ล้มเหลวใน install_log.txt

 ถาม: ขึ้นว่า Missing in game
 ตอบ: เวอร์ชันเกมอาจไม่ตรงกับที่ม็อดทำไว้ ให้ Verify integrity of game files
      แล้วติดตั้งใหม่ ถ้ายังขึ้นอีกต้องรอม็อดเวอร์ชันถัดไป

 ถาม: ขึ้นว่า NOTE: ... already the Thai version
 ตอบ: เคยลงม็อดไว้แล้วก่อนหน้า (เช่นก๊อปวางเอง) ไฟล์เหล่านั้นจึงไม่มีต้นฉบับ
      ภาษาอังกฤษสำรองไว้ ถ้าจะกลับเป็นอังกฤษให้ใช้ Verify integrity ของ Steam

 ถาม: อัปเดตเกม / Verify files แล้วภาษาไทยหาย
 ตอบ: รัน Install_ThaiMod.bat แล้วติดตั้งอีกครั้ง

 ถาม: บางข้อความยังเป็นภาษาอังกฤษ
 ตอบ: ตั้งใจไว้ ได้แก่ ชื่อทีมงานในเครดิต ชื่อแบรนด์ ตัวย่อ (BP, EXP)
      และหน้าร้านค้าออนไลน์ ซึ่งข้อความมาจากเซิร์ฟเวอร์ Steam ไม่ได้อยู่ในเกม

 ถาม: ทำไมข้อความในหน้าต่างเป็นภาษาอังกฤษ
 ตอบ: หน้าต่าง Command Prompt แสดงภาษาไทยไม่ได้ในเครื่องส่วนใหญ่
      จะขึ้นเป็นกล่องสี่เหลี่ยม จึงใช้ภาษาอังกฤษแทน
