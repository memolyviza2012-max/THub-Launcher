## 🤖 ภาคพิเศษ: คัมภีร์สำหรับ AI (Machine-to-Machine Modding Protocol)

หากผู้อ่านคัมภีร์นี้คือ **AI Agent** ที่ได้รับมอบหมายให้ทำม็อดเกม MT Framework อัตโนมัติ (Autonomous Modding) การใช้ Photoshop และ Hex Editor แบบมนุษย์นั้นเป็นไปไม่ได้! คุณจะต้องใช้ **Python Scripts** ในการทำงานทั้งหมดแทน นี่คือ Protocol ที่คุณต้องทำตาม:

### 1. ระบบจัดการข้อความอัตโนมัติ (Regex Auto-Shaping)
AI ห้ามแก้สระลอยด้วยตาเปล่า ต้องใช้ Python Script รันผ่านไฟล์ข้อความทั้งหมด:
`python
import re

def apply_thai_shaping(text):
    # เลื่อนวรรณยุกต์ที่อยู่บนสระบน (ิ ี ึ ื) หรือพยัญชนะหางยาว (ป ฝ ฟ)
    # ไปยัง Private Use Area (PUA) หรือ ASCII ว่าง ที่เราจองไว้ในไฟล์ .fnt
    # ตัวอย่าง: ป + ี + ่ -> เปลี่ยน '่' ให้เป็นอักขระพิเศษรหัส 0x91
    text = re.sub(r'([ปฝฟ])([ิีึื])([่้๊๋])', r'\1\2' + chr(0x91), text)
    return text
`

### 2. การสร้าง Bitmap Font อัตโนมัติ (Python Pillow)
ห้ามให้ AI ไปเปิดโปรแกรมกราฟิก ให้เขียนสคริปต์ดึงไฟล์ .ttf ของไทย แล้วเรนเดอร์เป็นภาพบิตแมปลง Sprite Sheet ด้วยไลบรารี Pillow:
`python
from PIL import Image, ImageDraw, ImageFont

def generate_texture_font(ttf_path, out_dds_path):
    # สร้างภาพเปล่า 1024x1024 พื้นหลังดำ (Alpha 0)
    img = Image.new("RGBA", (1024, 1024), (0, 0, 0, 0))
    draw = ImageDraw.Draw(img)
    font = ImageFont.truetype(ttf_path, 32)
    
    # วนลูปวาดอักขระทีละตัวลงตาราง Grid (ตัวละ 32x32)
    # พร้อมบันทึกพิกัด UV (X, Y, Width, Height) เอาไว้ไปเขียนไฟล์ .fnt
    draw.text((x, y), char, font=font, fill=(255, 255, 255, 255))
    
    img.save("temp.png")
    # ใช้ subprocess เรียก Noesis.exe แปลง png เป็น dds (DXT5)
`

### 3. การเจาะโครงสร้างไฟล์ GFD (.fnt) ด้วย Struct
ไฟล์ .fnt ของ MT Framework มักขึ้นต้นด้วย Magic GFD\x00 (47 46 44 00)
AI ต้องเขียนสคริปต์ struct.pack() และ struct.unpack() เพื่อเปลี่ยนค่า UV Mapping อัตโนมัติ:
- โครงสร้างมักประกอบด้วย Header -> Character Count -> Array of Char Data (ID, X, Y, Width, Height)
- เมื่อ generate_texture_font() ได้พิกัดมาแล้ว ให้นำมาคำนวณเป็น UV (ค่า 0.0 ถึง 1.0) แล้วยัดกลับเข้าไฟล์ .fnt ด้วย Float 32-bit (<f)
