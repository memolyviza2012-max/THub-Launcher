# Біблія: Адаптація проекту Marvel's GOTG для підтримки української мови (Ukrainian Localization)

Цей посібник крок за кроком (Step-by-Step) покаже, як модифікувати проект `version.dll` (який спочатку використовувався для тайської мови), щоб він міг читати та відображати **українську мову (кирилицю)** у грі Marvel's Guardians of the Galaxy.

---

## 🛠️ Короткий опис принципів роботи мода
Оригінальна гра використовує рушій Dawn Engine, який використовує функцію `FT_New_Memory_Face` (з бібліотеки FreeType) для завантаження шрифтів із файлів гри.
Наш мод використовує **MinHook** для втручання (Detour) у роботу двох основних частин:
1. **Font Hook:** Підміняє файл шрифту гри на наш власний (`font_th.ttf` -> буде змінено на `font_uk.ttf`).
2. **Text Hook:** Перехоплює англійський текст через `GetText` / `OnSetText` і замінює його перекладом, завантаженим із файлу `strings.json`.

Українська мова використовує **кирилицю (Cyrillic)**, яка працює в системі Unicode (UTF-8) як зазвичай, тому не потребує складного форматування тексту (Text Shaping), на відміну від тайської мови.

---

## 📝 Крок 1: Підготовка файлу українського шрифту (Cyrillic Font)

Ігровий рушій потребує файлу шрифту у форматі TrueType (`.ttf`) або OpenType (`.otf`), який підтримує кирилицю.

1. Знайдіть легкочитовний шрифт, який відповідає космічній/науково-фантастичній тематиці (наприклад, *Roboto*, *Open Sans* або ігрові шрифти), що має підтримку **кирилиці**.
2. Перейменуйте цей файл шрифту на `font_uk.ttf`.
3. Помістіть файл `font_uk.ttf` у ту саму папку, де знаходиться гра (там, де і `version.dll`, наприклад, у папку `retail/`).

> [!IMPORTANT]
> Розмір файлу шрифту не повинен бути занадто великим (не більше 5-10 МБ), оскільки мод повинен завантажувати цей шрифт у оперативну пам'ять (Buffer) і зберігати його там протягом усієї гри.

---

## 📝 Крок 2: Створення файлу перекладу `strings_uk.json`

Наш проект використовує формат JSON для зберігання перекладів. Структура має вигляд: `"Оригінальний англійський текст" : "Переклад українською"`.

1. Створіть файл з назвою `strings_uk.json`.
2. Збережіть файл у кодуванні **UTF-8 (або UTF-8 з BOM)**.
3. Приклад структури файлу:
```json
{
    "Start Game": "Почати гру",
    "Options": "Налаштування",
    "Quit": "Вийти",
    "I am Groot": "Я є Ґрут"
}
```
4. Помістіть файл `strings_uk.json` у папку з грою.

## 📝 Крок 3: Редагування вихідного коду C++ (Перемикання з тайської на українську)

Настав час відредагувати вихідний код у проекті (папка `02_Source_CPP`), щоб він завантажував український шрифт замість тайського.

### 3.1 Редагування файлу `TranslationHooks.cpp`

Знайдіть частину коду, пов'язану із завантаженням шрифту `font_th.ttf`, і замініть її на `font_uk.ttf`.

```diff
- // Змінні для тайського шрифту
- void* g_thai_font_buffer = nullptr;
- DWORD g_thai_font_size = 0;
- bool g_thai_font_loaded = false;

+ // Змінні для українського шрифту
+ void* g_uk_font_buffer = nullptr;
+ DWORD g_uk_font_size = 0;
+ bool g_uk_font_loaded = false;
```

У функції, яка встановлює Hook (наприклад, `install_all_hooks` або там, де викликається `CreateFileW`):

```diff
- std::wstring font_path = std::wstring(exe_dir) + L"font_th.ttf";
+ std::wstring font_path = std::wstring(exe_dir) + L"font_uk.ttf";

  HANDLE hFont = CreateFileW(font_path.c_str(), GENERIC_READ, ...);
  if (hFont != INVALID_HANDLE_VALUE) {
-     g_thai_font_size = GetFileSize(hFont, nullptr);
-     g_thai_font_buffer = new char[g_thai_font_size];
+     g_uk_font_size = GetFileSize(hFont, nullptr);
+     g_uk_font_buffer = new char[g_uk_font_size];
```

А також у функції `detour_FT_New_Memory_Face` (яка підміняє шрифт у пам'яті):

```diff
- if (g_thai_font_loaded && (file_size == 404856 || file_size == 241940)) {
+ if (g_uk_font_loaded && (file_size == 404856 || file_size == 241940)) {
      // Підміна шрифту
-     return g_orig_FT_New_Memory_Face(library, g_thai_font_buffer, g_thai_font_size, face_index, aface);
+     return g_orig_FT_New_Memory_Face(library, g_uk_font_buffer, g_uk_font_size, face_index, aface);
  }
```

> [!NOTE]
> Число `file_size == 404856` — це розмір файлу оригінального англійського шрифту гри (UI Font). Якщо ви хочете замінити певний шрифт, вам потрібно дізнатися розмір його пам'яті, що можна зробити, переглянувши файл `GOTG_Mod.log` при увімкненому режимі Debug.

### 3.2 Редагування файлу `GOTG_Mod.ini` (Для користувача)

Налаштуйте конфігураційний файл, щоб він вказував на файл JSON з українським перекладом замість тайського.

```ini
[Language]
EnableTranslation=1
; Вказує на файл з українським перекладом
StringsJSON=strings_uk.json
```

## 📝 Крок 4: Компіляція та використання

1. Відкрийте Command Prompt або PowerShell у папці `02_Source_CPP`.
2. Запустіть скрипт збірки: `build_cli.bat`.
3. Проект буде скомпільований у файл `version.dll`.
4. Скопіюйте всі наведені нижче файли в папку `retail` вашої гри:
   - `version.dll` (який ми щойно скомпілювали)
   - `font_uk.ttf` (український шрифт)
   - `strings_uk.json` (переклади)
   - `GOTG_Mod.ini` (файл налаштувань)

## 💡 Додаткові поради та усунення несправностей (Troubleshooting)

- **Текст відображається як квадратики (Tofu / □□□):** 
  Це означає, що файл `font_uk.ttf`, який ви використовуєте, не містить таблиці символів (Glyph) для кирилиці. Спробуйте змінити його на інший шрифт, який точно на 100% підтримує кирилицю.
- **Гра вилітає під час завантаження меню:** 
  Це може статися через занадто великий розмір файлу шрифту або через те, що буфер у коді Hook замалий. Перевірте `safe_buf` у файлі `TranslationHooks.cpp`, щоб переконатися, що він підтримує достатню довжину рядка (українська використовує UTF-8, де 1 символ може займати до 2-3 байтів).
- **Використання Regex або змінних:**
  У грі є змінні в тексті, такі як `[BTN_A]` або `{0}`. Обов'язково залишайте ці змінні у `strings_uk.json` у такому самому вигляді. Не видаляйте і не перекладайте їх, оскільки це призведе до зависання гри під час спроби відобразити кнопку.
