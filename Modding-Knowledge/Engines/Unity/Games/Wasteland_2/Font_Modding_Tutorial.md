# 📖 คัมภีร์จับมือทำ: การเปลี่ยนฟอนต์ภาษาไทยเกม Wasteland 2 (แก้สระลอย 100%)

บทความนี้จะสอนวิธีเปลี่ยนฟอนต์ภาษาไทยในเกม Wasteland 2 Director's Cut โดยใช้เทคนิค **PUA Sync** ซึ่งจะการันตีได้ว่าสระและวรรณยุกต์จะไม่ลอย และไม่ล่องหนหายไปแน่นอนครับ

---

## 🛠️ สิ่งที่ต้องเตรียม
1. **ไฟล์ฟอนต์ภาษาไทย** (ไฟล์ .ttf ต้นฉบับที่คุณอยากใช้ เช่น CkOtter หรือ IBMPlexSans)
2. **โปรแกรม Python** (ติดตั้ง `fontTools` และ `UnityPy` ผ่านคำสั่ง `pip install fonttools unitypy`)
3. **ไฟล์ Mapping ของ PUA-Thai-Converter** (ไฟล์ `mapping.json` ที่ใช้สำหรับแปลงข้อความ)
4. **สคริปต์ทำงานของเรา 2 ตัว** (อยู่ในโฟลเดอร์ `05_Scripts_and_Tools` ของโปรเจกต์):
   - `custom_font_pua_generator.py` (ตัวหลอมฟอนต์)
   - `replace_pua_font.py` (ตัวยัดฟอนต์เข้าเกม)

---

## 🎯 ขั้นตอนที่ 1: เตรียมฟอนต์ของคุณ

เป้าหมายคือเราต้องนำฟอนต์ต้นฉบับของคุณ มา "หลอมรวม" กับรหัส PUA เพื่อสร้างเป็นภาพสระลอยขึ้นมา

1. เปิดไฟล์ `custom_font_pua_generator.py` ด้วยโปรแกรม Notepad หรือ VS Code
2. มองหาบรรทัดที่เขียนว่า `ORIGIN_FONT = r"..."` (ช่วงบรรทัดที่ 7)
3. เปลี่ยนที่อยู่ไฟล์ในเครื่องหมายคำพูด ให้ชี้ไปยังฟอนต์ `.ttf` ที่คุณต้องการใช้ เช่น:
   ```python
   ORIGIN_FONT = r"E:\Mod_Workspace\Tool\1_ThaiFont\Font_origin\CkOtter\CkOtterDemo.ttf"
   ```
4. กด Save ปิดไฟล์ได้เลย

---

## 🎯 ขั้นตอนที่ 2: รันเครื่องหลอมฟอนต์ (Generate PUA Font)

1. เปิด Command Prompt หรือ PowerShell ขึ้นมา
2. พิมพ์คำสั่งเพื่อไปยังโฟลเดอร์เครื่องมือ:
   ```powershell
   cd E:\Mod_Workspace\Wasteland_2\05_Scripts_and_Tools
   ```
3. สั่งรันสคริปต์หลอมฟอนต์ด้วยคำสั่ง:
   ```powershell
   python custom_font_pua_generator.py
   ```
4. **รอสักครู่!** โปรแกรมจะอ่านฟอนต์ของคุณ และสร้างรหัสสระลอยขึ้นมากว่า 1,800 ตัวอักษร เมื่อเสร็จแล้วคุณจะได้ไฟล์ใหม่ชื่อ **`Wasteland2_PUA.ttf`** โผล่ขึ้นมา

---

## 🎯 ขั้นตอนที่ 3: ยัดฟอนต์เข้าเกม (Inject Font)

ฟอนต์ของเกม Wasteland 2 ไม่ได้วางอยู่ข้างนอกธรรมดา แต่ถูกฝังอยู่ในไฟล์ `.assets` ถึง 3 ไฟล์ (`resources.assets`, `sharedassets5.assets`, `sharedassets6.assets`) เราจึงต้องใช้สคริปต์ยัดเข้าไป

1. ในหน้าต่าง Command Prompt ตัวเดิม ให้รันคำสั่ง:
   ```powershell
   python replace_pua_font.py
   ```
2. สคริปต์นี้จะทำหน้าที่:
   - เปิดไฟล์ `.assets` ของเกมทั้งหมดขึ้นมา
   - ค้นหา Object ประเภท Font
   - นำไฟล์ `Wasteland2_PUA.ttf` ของเราไป "เขียนทับ" ฟอนต์ดั้งเดิมทั้ง 6 ตัว
   - บันทึกไฟล์ `.assets` และนำไปวางทับในโฟลเดอร์ของเกม (`WL2_Data`) ให้อัตโนมัติ!
3. เมื่อขึ้นข้อความว่า `All fonts replaced with PUA version and deployed!` เป็นอันเสร็จพิธี

---

## 🎮 ขั้นตอนที่ 4: เข้าเกมไปดูผลงาน!
กดเปิดเกม Wasteland 2 Director's Cut จาก Steam ได้เลย
หากคุณเห็นเมนู "เริ่มเกมใหม่" แสดงผลด้วยฟอนต์ใหม่ที่คุณเลือกไว้ โดยที่สระ ิ ่ ไม่หายไปไหน แสดงว่าคุณทำสำเร็จแล้วครับ! 🎉

> **💡 เกร็ดความรู้ (ทำไมถึงต้องทำแบบนี้?):**
> Unity 5 ไม่รู้จักสระลอยของไทย ถ้าเรายัดฟอนต์ปกติเข้าไป คำว่า "เริ่ม" สระอิ กับไม้เอกจะทับกัน เราเลยต้องแปลงข้อความเป็นรหัส PUA (หลอกเกมให้ใช้ตัวอักษรพิเศษ) แต่ปัญหาคือตัวหนังสือมักจะ "ล่องหน" การแก้ปัญหาที่เด็ดขาดคือ **การหลอมฟอนต์ (ขั้นตอนที่ 2) โดยใช้ตาราง Mapping อันเดียวกับตัวแปลงข้อความเป๊ะๆ** นั่นเองครับ
