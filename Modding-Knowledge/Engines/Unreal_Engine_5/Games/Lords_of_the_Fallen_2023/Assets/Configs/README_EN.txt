## Installation

1. Close the game before installing.
2. Extract the ZIP file.
3. Copy this file:

```text
pakchunk99-Windows.pak
```

to the game Paks folder:

```text
C:\Program Files (x86)\Steam\steamapps\common\Lords of the Fallen\LOTF2\Content\Paks\
```

4. Launch the game normally.

## Uninstallation

Remove this file from the `Paks` folder:

```text
pakchunk99-Windows.pak
```

## Notes

- This mod uses a pak override structure and does not directly modify the original game files.
- If the game is updated and the translation no longer works, remove `pakchunk99-Windows.pak` and wait for an updated version of the mod.
- If another localization mod uses a higher-priority pak name, the pak order may need to be adjusted.
