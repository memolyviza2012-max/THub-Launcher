# คู่มือการใช้งานระบบวิเคราะห์ไฟล์ทั้งระบบอัจฉริยะ (TStudio Whole-File Game Localization Intelligence)

## 1. บทนำ (Introduction)
ในงานแปลเกมระดับมืออาชีพ การพิจารณาข้อความทีละบรรทัดโดดๆ (Per-row Tagging) ไม่เพียงพอต่อการรักษาคุณภาพและความสอดคล้องของเนื้อหาทั้งเกม
ระบบ **TStudio Whole-File Localization Intelligence Engine** ได้รับการพัฒนาขึ้นเพื่อวิเคราะห์ไฟล์งานแปลทั้งหมดแบบองค์รวม (Whole-File Ecosystem) ผ่าน 5 มิติอัจฉริยะ:
1. **Holistic Game Matrix & Content Breakdown**: แจกแจงสัดส่วนประเภทข้อความ นับคำ ประเมินงาน และคำนวณคะแนนคุณภาพ (Integrity Score)
2. **Dramatis Personae & Cast Discovery**: ทำเนียบตัวละคร วิเคราะห์จำนวนบทพูดของแต่ละคน และชี้จุดที่ตัวละครปรากฏตัวครั้งแรก
3. **Semantic Asset Bundling**: รวมกลุ่มสกิล เควสต์ และไอเทม (Name + Description + Tooltip) ข้ามแถวให้อัตโนมัติ
4. **Automated Entity & Glossary Miner**: ขุดค้น Proper Nouns และคำเฉพาะที่พบบ่อย พร้อมปุ่มเพิ่มเข้า Glossary ใน 1 คลิก
5. **Quality, Conflict & Tag Integrity Auditor**: ตรวจจับประโยคที่แปลไม่ตรงกัน (1-to-Many Conflict) และแท็กตัวแปรเกมที่เสียหาย

---

## 2. วิธีการเปิดใช้งาน (How to Use)
สามารถเปิดหน้าต่างศูนย์วิเคราะห์ได้ 2 วิธี:
1. **ปุ่มบนหน้าจอหลัก**: คลิกที่ปุ่ม **`📊 วิเคราะห์ทั้งไฟล์`** ข้างกล่องฟิลเตอร์หมวดหมู่ในตารางหลัก
2. **เมนูเครื่องมือ**: ไปที่แถบเมนู **เครื่องมือ (Tools) ➔ `📊 วิเคราะห์โครงสร้างและคำศัพท์ทั้งไฟล์ (Deep File Analyzer)`** หรือกดปุ่มลัด **`Ctrl+Shift+A`**

## 3. หน้าต่างและแท็บการทำงาน (Dashboard Features)

### 3.1 การ์ดดัชนีชี้วัดหลัก (Header KPI Cards)
- **แถวทั้งหมด (Total Rows)**: จำนวนบรรทัดทั้งหมดในโปรเจกต์
- **คำต้นฉบับ (Total Words)**: จำนวนคำภาษาอังกฤษทั้งหมด
- **ความคืบหน้า (Progress %)**: ร้อยละการแปลที่เสร็จสิ้น
- **คะแนนความถูกต้อง (Integrity Score)**: ประเมินคะแนนเต็ม 100 หักคะแนนตามข้อผิดพลาดแท็กและคำแปลขัดแย้ง
- **คำแปลขัดแย้ง (Conflicts)**: จำนวนประโยคต้นฉบับที่ถูกแปลขัดแย้งกัน
- **แท็กตัวแปรเสีย (Tag Errors)**: จำนวนแถวที่แท็กตัวแปรเกม `{0}`, `%s`, `<color>` เสียหาย

### 3.2 แท็บที่ 1: 📊 สัดส่วนเนื้อหาเกม (Overview)
- แสดงตารางแจกแจงเนื้อหาตามหมวดหมู่: บทสนทนา, สกิล, ไอเทม, เควสต์, ตัวละคร, ระบบ UI
- แสดงเปอร์เซ็นต์ความคืบหน้าของแต่ละหมวดหมู่อย่างละเอียด

### 3.3 แท็บที่ 2: 👥 ทำเนียบตัวละคร (Cast & Dialogue)
- แสดงรายชื่อตัวละครทั้งหมดที่มีบทพูดในเกม จัดอันดับตามจำนวนประโยค
- แสดงชื่อภาษาไทย และตัวอย่างประโยคพูด
- **Interactive Jump**: ดับเบิลคลิกที่ชื่อตัวละคร ➔ ระบบจะกระโดดไปไฮไลต์แถวแรกของตัวละครนั้นในตารางหลักทันที!

### 3.4 แท็บที่ 3: 📦 ชุดสกิล/เควสต์ (Asset Bundles)
- มัดรวมข้อมูลสกิลและไอเทมใน Unreal Engine / Unity (เช่น `GA_AbilityName_Name` คู่กับ `GA_AbilityName_Description` และ `Tooltip`)
- กรองดูเฉพาะชุดที่แปลไม่ครบได้
- ดับเบิลคลิกเพื่อกระโดดไปตรวจสอบแถวในตารางหลัก

### 3.5 แท็บที่ 4: 🧠 ขุดคำศัพท์เฉพาะ (Mined Entities & Glossary Suggestions)
- สแกนหา Proper Nouns และคำศัพท์เฉพาะที่พบบ่อยในเกม
- แสดงความถี่ และตัวอย่างประโยค
- **1-Click Glossary Addition**: คลิกปุ่ม `+ เพิ่มเข้า Glossary` เพื่อบรรจุคำศัพท์เข้าฐานข้อมูลทันที หรือเลือกหลายแถวแล้วกด `➕ เพิ่มคำที่เลือกเข้า Glossary ทั้งหมด`

### 3.6 แท็บที่ 5: ⚠️ ตรวจจับความขัดแย้ง & แท็กโค้ด (Integrity Audit)
- **ประโยคที่แปลขัดแย้งกัน (1-to-Many Conflicts)**: แสดงประโยคภาษาอังกฤษที่เหมือนกัน แต่ถูกแปลไทยไว้หลายแบบ พร้อมบอกจำนวนจุดที่ใช้แต่ละแบบ
- **แท็กตัวแปรเกมสูญหาย (Tag Errors)**: แสดงแถวที่แท็กเกม `{0}`, `{name}`, `%s`, `<b>`, `\n` ขาดหายหรือถูกแปลผิดเพี้ยน ดับเบิลคลิกเพื่อกระโดดไปแก้ไขได้ทันที
