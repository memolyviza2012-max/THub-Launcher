## 1. ที่มาและปัญหาของคำว่า "Checkpoint" (Context & Problem Statement)

คำว่า **"Checkpoint"** ในวิดีโอเกมเป็นคำศัพท์ที่มีสองบริบทหลัก (Dual-Context) ที่มีความหมายและอารมณ์ของภาษาแตกต่างกันโดยสิ้นเชิง:

### ปัญหาที่ 1: การแปลตรงตัวของ Machine Translation (MT Blunder)
- ในระบบแปลภาษาอัตโนมัติ (Google Translate, DeepL) หรือ LLM ทั่วไป คำว่า `Checkpoint` มักถูกแปลทื่อๆ เป็น **"จุดตรวจ"**
- เมื่อผู้เล่นเล่นเกมทั่วไปแล้วผ่านจุดเซฟ แต่เกมขึ้นแจ้งเตือนว่า *"ถึงจุดตรวจแล้ว"* หรือในเมนูเขียนว่า *"เริ่มใหม่จากจุดตรวจ"* ทำให้ผู้เล่นรู้สึกเหมือนขับรถผ่านด่านตรวจ มากกว่ากำลังผจญภัยในเกม

### ปัญหาที่ 2: การแทนที่แบบสุ่มสี่สุ่มห้าโดยไม่ดูบริบท (Blind Global Replacement Flaw)
- หากแก้ปัญหาที่ 1 โดยการบังคับเปลี่ยนคำว่า Checkpoint ทั้งหมดเป็น **"เช็คพอยท์"** โดยไม่ตรวจดูบริบทของประโยค จะส่งผลให้ข้อความบทสนทนาและเควสต์ในเกมทหาร แอ็กชัน และสงคราม (เช่น Call of Duty, Cyberpunk, Metal Gear Solid, GTA) เสียหายอย่างรุนแรง
- ตัวอย่างเช่น:
  - `Enemy checkpoint ahead` ➔ ถูกแก้เป็น ❌ *"เช็คพอยท์ของศัตรูอยู่ข้างหน้า"* (ทำลายอรรถรสอย่างสิ้นเชิง ควรเป็น ✅ *"ด่านตรวจของศัตรูอยู่ข้างหน้า"*)
  - `Guards at the checkpoint` ➔ ถูกแก้เป็น ❌ *"ยามที่เช็คพอยท์"* (ควรเป็น ✅ *"ยามที่ด่านตรวจ"*)
  - `Infiltrate and clear the checkpoint` ➔ ถูกแก้เป็น ❌ *"แทรกซึมและกวาดล้างเช็คพอยท์"* (ควรเป็น ✅ *"แทรกซึมและกวาดล้างด่านตรวจ"*)

**สรุป:** ระบบ QA และ AI ต้องสามารถ **แยกแยะบริบท 2 รูปแบบอย่างแม่นยำ 100%** โดยไม่อนุญาตให้แก้ไขด่านตรวจในเนื้อเรื่องเป็นเช็คพอยท์เด็ดขาด

## 2. พิธีสารการแยกแยะบริบท Checkpoint 2 กรณี (Dual-Context Protocol)

```
                                 ┌─────────────────────────┐
                                 │   Word: "Checkpoint"    │
                                 └────────────┬────────────┘
                                              │
                      ┌───────────────────────┴───────────────────────┐
                      ▼                                               ▼
         [กรณีที่ 1: กลไกเซฟ/ความคืบหน้าเกม]             [กรณีที่ 2: ด่านทหาร/ตำรวจ/ชายแดนในฉาก]
         Save Mechanic / Respawn / UI                    In-World Physical Outpost / Roadblock
         ─────────────────────────────────               ─────────────────────────────────────
         • สัญญาณ: reached, last, restart,              • สัญญาณ: military, police, border, enemy,
           save, reload, race, stage progress              soldier, guards, infiltrate, clear, outpost
         • ✅ แปลว่า: "เช็คพอยท์" / "จุดเช็คพอยท์"          • ✅ แปลว่า: "ด่านตรวจ" / "จุดตรวจ"
         • ❌ ห้ามแปล: "จุดตรวจ" หรือ "ด่านตรวจ"            • ❌ ห้ามแก้เป็น: "เช็คพอยท์" เด็ดขาด!
```

### 🟢 กรณีที่ 1: กลไกบันทึกเกม / จุดเกิดใหม่ / UI ความคืบหน้า (Save Mechanic & Progress)
- **นิยาม:** จุดบันทึกตำแหน่งเซฟของผู้เล่น, จุดเกิดใหม่เมื่อตัวละครตาย, หรือจุดเช็คพอยท์บอกระยะทางในเกมแข่งรถ
- **คำแปลที่ถูกต้อง:** **"เช็คพอยท์"** หรือ **"จุดเช็คพอยท์"**
- **ข้อห้าม:** ❌ ห้ามแปลว่า *"จุดตรวจ"* หรือ *"ด่านตรวจ"*
- **ตัวอย่าง:**
  - `Checkpoint reached` ➔ `ถึงจุดเช็คพอยท์แล้ว` / `เช็คพอยท์` (ไม่ใช่ `ถึงจุดตรวจแล้ว`)
  - `Restart from checkpoint` ➔ `เริ่มใหม่จากจุดเช็คพอยท์` (ไม่ใช่ `เริ่มใหม่จากจุดตรวจ`)
  - `Last checkpoint` ➔ `จุดเช็คพอยท์ล่าสุด`
  - `Next checkpoint in 200m` ➔ `เช็คพอยท์ถัดไปในอีก 200 เมตร`

### 🔴 กรณีที่ 2: ด่านตรวจทหาร / ตำรวจ / กองกำลังศัตรู / ชายแดนในเนื้อเรื่อง (Physical In-World Outpost)
- **นิยาม:** ด่านตรวจค้นทางกายภาพ, จุดตรวจความปลอดภัย, ด่านสกัดกั้น, ป้อมยามของศัตรู, ด่านตรวจคนเข้าเมือง หรือสิ่งกีดขวางบนถนนในเนื้อเรื่องของเกม
- **คำแปลที่ถูกต้อง:** **"ด่านตรวจ"** หรือ **"จุดตรวจ"**
- **ข้อห้าม:** ❌ **ห้ามแปลหรือแทนที่ด้วย "เช็คพอยท์" เด็ดขาด!**
- **ตัวอย่าง:**
  - `Military checkpoint ahead` ➔ `ด่านตรวจทหารอยู่ข้างหน้า`
  - `Enemy checkpoint spotted near the bridge` ➔ `ตรวจพบด่านตรวจของศัตรูใกล้สะพาน` (ห้าม `เช็คพอยท์ของศัตรู`)
  - `Police checkpoint on the highway` ➔ `ด่านตรวจตำรวจบนทางหลวง` / `จุดตรวจตำรวจบนทางหลวง`
  - `Border checkpoint` ➔ `ด่านตรวจชายแดน`
  - `Infiltrate and clear the checkpoint` ➔ `แทรกซึมและกวาดล้างด่านตรวจ`
  - `Guards stationed at the checkpoint` ➔ `ยามที่ประจำการอยู่ที่ด่านตรวจ`

## 3. สัญญาณคำค้นตรวจจับบริบท (Detection Keyword Signals & Regex)

ระบบ QA ทั้งฝั่ง Python (`thai_checker.py`) และ TypeScript (`thaiChecker.ts`) ใช้ชุดคำสัญญาณ (Keyword Signals) เพื่อจำแนกบริบทดังนี้:

### สัญญาณบริบททางกายภาพ (Physical Outpost Signals)
- **ภาษาอังกฤษ (Source):**
  `military`, `police`, `security`, `border`, `customs`, `immigration`, `guard`, `guards`, `sentry`, `enemy`, `enemies`, `rebel`, `rebels`, `hostile`, `hostiles`, `soldier`, `soldiers`, `officer`, `army`, `road`, `roads`, `highway`, `street`, `bridge`, `outpost`, `base`, `camp`, `gate`, `blockade`, `barrier`, `roadblock`, `fence`, `perimeter`, `patrol`, `smuggle`, `infiltrate`, `attack`, `assault`, `capture`, `clear`, `destroy`, `defend`, `approach`, `stationed`, `search`, `inspect`, `bribe`, `convoy`
- **ภาษาไทย (Target):**
  `ทหาร`, `ตำรวจ`, `ความมั่นคง`, `ความปลอดภัย`, `ชายแดน`, `ตรวจคนเข้าเมือง`, `ศุลกากร`, `ยาม`, `เวรยาม`, `ทหารยาม`, `กองรักษาการณ์`, `สายตรวจ`, `ลาดตระเวน`, `ศัตรู`, `กบฏ`, `โจร`, `คนร้าย`, `บนถนน`, `ทางหลวง`, `สะพาน`, `ค่าย`, `ฐาน`, `ประตู`, `สิ่งกีดขวาง`, `ด่านสกัด`, `ปิดกั้น`, `แทรกซึม`, `บุก`, `โจมตี`, `ทำลาย`, `ยึด`, `ป้องกัน`, `ตรวจค้น`

### สัญญาณบริบทจุดเซฟเกม (Save Mechanic Signals)
- **ภาษาอังกฤษ (Source):**
  `reached`, `reach`, `last`, `previous`, `next`, `restart`, `reload`, `return to`, `save at`, `auto-save`, `autosave`, `race`, `stage`, `progress`, `checkpoint active`, `new checkpoint`, หรือคำว่า `checkpoint` เดี่ยวๆ

## 4. บัญชีดำคำแปลกลไกเกมผิดมหันต์ (Gaming MT Blunder Blacklist)

| ศัพท์ภาษาอังกฤษ (Source) | คำแปลทางการที่ถูกต้อง | คำแปลต้องห้าม (Strict MT Trap) | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| **Checkpoint** (Save) | **เช็คพอยท์ / จุดเช็คพอยท์** | ❌ **จุดตรวจ, ด่านตรวจ** | ระบบบันทึกตำแหน่งเซฟย่อย/เกิดใหม่ |
| **Checkpoint** (Physical) | **ด่านตรวจ / จุดตรวจ** | ❌ **เช็คพอยท์** | ด่านตรวจทหาร/ตำรวจ/ศัตรูในฉาก |
| **Strike** | **ฟาดฟัน / จู่โจม / ประหาร** | ❌ **นัดหยุดงาน, ประท้วงหยุดงาน** | ทักษะการโจมตีหรืออาวุธ |
| **Cast / Casting** | **ร่าย / กำลังร่ายเวท** | ❌ **หล่อโลหะ, คัดเลือกนักแสดง** | การใช้เวทมนตร์หรือสกิล |
| **Cooldown** | **คูลดาวน์ / เวลารอใช้ใหม่** | ❌ **เย็นลง, การระบายความร้อน** | ระยะเวลาพักฟื้นก่อนใช้สกิลซ้ำ |
| **Passive Skill** | **สกิลติดตัว / ทักษะติดตัว** | ❌ **ทักษะเฉยชา, ไม่กระตือรือร้น** | สกิลทำงานอัตโนมัติตลอดเวลา |
| **Active Skill** | **สกิลกดใช้ / ทักษะกดใช้** | ❌ **ทักษะคล่องแคล่ว, กระตือรือร้น** | สกิลที่ต้องกดปุ่มสั่งการ |
| **Critical Hit** | **คริติคอล / โจมตีติดคริ** | ❌ **การโจมตีวิกฤต, วิกฤตการณ์** | โจมตีโดนจุดสำคัญรุนแรงพิเศษ |
| **Bleed / Bleeding** | **ติดเลือดไหล / เลือดออก** | ❌ **ตกเลือด, เลือดออกทางแผล** | สถานะผิดปกติสร้างดาเมจต่อเนื่อง |
| **Stun** | **สตัน / มึนงง** | ❌ **ทำให้ตกตะลึง, ทำให้ประหลาดใจ** | สถานะหยุดการเคลื่อนไหว |
| **Lifesteal** | **ดูดเลือด** | ❌ **ขโมยชีวิต** | ดูดพลังชีวิตจากศัตรูมาเพิ่มให้ตนเอง |
| **Respawn / Spawn** | **เกิดใหม่ / จุดเกิด** | ❌ **วางไข่, การฟักตัว** | ตัวละครเกิดใหม่ในฉาก |
| **Breeches** (Medieval) | **กางเกง...** (เช่น กางเกงผู้ฝึกเวท) | ❌ **เด็กฝึกงาน, ขาสั้นเด็กฝึกงาน** | กางเกงรัดเข่าโบราณ |
| **Ring of Assurance** | **แหวนพิทักษ์ชีพ** | ❌ **แหวนประกันชีวิต** | เครื่องรางป้องกัน |
| **Ring of Insomnolence** | **แหวนต้านนิทรา** | ❌ **แหวนแห่งการนอนไม่หลับ** | เครื่องรางต้านสถานะหลับ |
| **Firearms Models** | **คงรหัสเดิม:** M60, M4A1, AK-47 | ❌ **เอ็ม 60, เอเค 47, กล็อก 19** | ห้ามทับศัพท์ชื่อรุ่นปืนเป็นตัวอักษรไทย |
