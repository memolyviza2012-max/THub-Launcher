# คู่มือสถาปัตยกรรม Workspace แบบหลายหน้า (TStudio Multi-Page Workspace Architecture Guide)

> **เอกสารคู่มือเทคนิคสำหรับการออกแบบหน้าจอและการจัดวาง Workspace ของ TStudio**  
> **หมวดหมู่**: Techniques / GUI Architecture & Ergonomics  
> **เวอร์ชัน**: 1.0 (ระบบ Full-Page Workspace Stack via QStackedWidget)

---

## 1. บทนำและปัญหาเดิม (Background & Problem)

เดิมที TStudio ถูกออกแบบให้มี 3 คอลัมน์หลักสำหรับการแปลภาษา (CAT Studio):
1. คอลัมน์ 1: ตารางงานแปล (Translation Table View)
2. คอลัมน์ 2: คลังคำศัพท์ (Glossary Window)
3. คอลัมน์ 3: พื้นที่บรรณาธิการ 3 ชั้น (3-Tier Segment Stack)

เมื่อมีการเพิ่มโมดูล **TRun (Batch AI Runner)** สำหรับการรันแปลอัตโนมัติหลายไฟล์/ทั้งไฟล์เดิม การนำ TRun มายัดเป็น QDockWidget ด้านขวา (RightDockWidgetArea) ส่งผลให้:
- หน้าจอถูกแบ่งเป็น 4 แผงพร้อมกันในแนวนอน
- ความกว้างของตารางและกล่องแปลถูกบีบเหลือไม่ถึง 250-300px
- แผงควบคุม TRun ถูกเบียดจน Terminal Log และพารามิเตอร์เลื่อนอ่านได้ลำบาก

## 2. โครงสร้างสถาปัตยกรรมใหม่ (Full-Page Workspace Stack)

เพื่อแก้ปัญหาพื้นที่ทำงานอย่างถาวร TStudio จึงเปลี่ยนมาใช้ **QStackedWidget** คุมพื้นที่ทำงานหลักทั้งหมดใน Central Widget:

`
┌────────────────────────────────────────────────────────────────────────┐
│ 1. TOP HEADER BAR: Logo | Profile | Model Selector | Model Stats       │
├────────────────────────────────────────────────────────────────────────┤
│ 2. WORKSPACE BAR: [ ✍️ แปลภาษา (CAT Studio) ] [ ⚡ รันแปลอัตโนมัติ (TRun) ] │
├────────────────────────────────────────────────────────────────────────┤
│ 3. QStackedWidget (สลับหน้าทำงาน 100% Full Width)                      │
│                                                                        │
│  [Page 0: CAT Studio]                                                  │
│  ┌────────────────────┬────────────────────┬────────────────────────┐  │
│  │ Col 1: Table View  │ Col 2: Glossary    │ Col 3: Segment Editor  │  │
│  │ (36% Width)        │ (32% Width)        │ (32% Width)            │  │
│  └────────────────────┴────────────────────┴────────────────────────┘  │
│                                                                        │
│  ──────────────────────────── หรือ (OR) ─────────────────────────────  │
│                                                                        │
│  [Page 1: TRun Dedicated Dashboard]                                    │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ ⚡ TRun Navigation Bar [ 🔙 กลับไปหน้าแปลภาษา (CAT Studio) (F1) ] │  │
│  ├──────────────────────────────────────────────────────────────────┤  │
│  │ 🎯 Translation Target (ไฟล์เปิดอยู่ vs คิวไฟล์ภายนอก)            │  │
│  ├──────────────────────────────┬───────────────────────────────────┤  │
│  │ Left: Engine Config          │ Right: Progress & Live Terminal   │  │
│  │ (Batch, Threads, Filters)    │ (Terminal Logs, Queue, Actions)   │  │
│  └──────────────────────────────┴───────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
`

## 3. การใช้งานและการสลับโหมด (Workspace Switching)

1. **การสลับหน้าด้วยปุ่มบนแถบ WORKSPACE**:
   - คลิกปุ่ม ✍️ แปลภาษา (CAT Studio) หรือกดปุ่มคีย์ลัด **F1** ➔ หน้าจอจะพลิกไปหน้า CAT Studio ทันที
   - คลิกปุ่ม ⚡ รันแปลอัตโนมัติ (Batch AI Runner) หรือกดปุ่มคีย์ลัด **F2** ➔ หน้าจอจะพลิกไปหน้า TRun ทันที
2. **ปุ่มย้อนกลับภายใน TRun**:
   - ภายในหน้า TRun จะมีปุ่ม [ 🔙 กลับไปหน้าแปลภาษา (CAT Studio) [F1] ] ที่แถบด้านบน เพื่อความสะดวกในการคลิกกลับ
3. **การทำงานเบื้องหลัง (Background Resilience)**:
   - เนื่องจาก QStackedWidget เก็บ Widget ทั้งสองหน้าไว้ในหน่วยความจำโดยไม่ได้ทำลายทิ้ง (No Re-instantiation) ดังนั้น **หาก TRun กำลังรันแปลอยู่ ผู้ใช้สามารถสลับกลับไปดูหน้า CAT Studio หรือสลับไปมาได้อย่างอิสระโดยที่กระบวนการแปลไม่หยุดชะงัก**
