# TStudio & TRun Translation Clearing Architecture Guide
*ระบบจัดการและล้างคำแปล (Clear Translations) แบบแยกส่วนระดับแถวและไฟล์ทั้งระบบ*

## 1. บทนำและแนวคิด (Overview & Core Philosophy)
ในการทำงานแปลเกมด้วย AI หรือเครื่องมือ CAT (Computer-Assisted Translation) เกิดสถานการณ์ที่ผู้ใช้ต้องการ:
1. **ล้างผลแปลบางแถว** ที่ต้องการให้ AI แปลใหม่ด้วย Prompt หรือสไตล์อื่น
2. **ล้างเฉพาะผลแปลแนะนำจาก AI (ai_ref)** โดยเก็บรักษาคำแปลภาษาไทยที่มนุษย์ตรวจแก้แล้ว (trans)
3. **ล้างคำแปลทั้งหมดในไฟล์ (Clear All Translations)** เพื่อเตรียมรัน Batch รอบใหม่ตั้งแต่ต้น

### หลักความปลอดภัยของข้อมูล (Data Integrity Safety Rule)
- **ห้ามทำลายข้อมูลเกมเด็ดขาด**: ต้องแยกความแตกต่างระหว่างการ **'ล้างคำแปล (Clear Translation)'** และการ **'ลบบรรทัด (Delete Row)'** ออกจากกันอย่างเด็ดขาด
  - **ลบคำแปล (Clear Translation)**: ข้อความต้นฉบับภาษาอังกฤษ (Source Text) และ Game Key / Row ID **ยังคงอยู่ครบถ้วน 100%** เพียงแค่รีเซ็ตสถานะกลับเป็น รอแปล
  - **ลบแถว (Delete Row)**: ตัดบรรทัดนั้นออกจากไฟล์ CSV ของเกมอย่างถาวร

## 2. โครงสร้างข้อมูลและสถานะ (Data Model Structure)

ใน TranslationModel ข้อมูลแต่ละแถวจะถูกจัดเก็บใน Dictionary:
`python
item = {
    'id': '1001',
    'key': 'UI_START_GAME',
    'source': 'Start Game',
    'ai_ref': 'เริ่มเกม',       # คอลัมน์ แปลโดย AI (Column 3)
    'trans': 'เริ่มเกม',        # คอลัมน์ คำแปลภาษาไทย (Column 4)
    'is_th': True,             # ธงตรวจสอบว่ามีภาษาไทยหรือไม่
    'qa_failed': False         # ธงการตรวจ QA (Tags / Placeholders)
}
`

### การล้างคำแปล 2 รูปแบบ:
1. **Full Reset (only_ai=False)**:
   - item['trans'] = ''
   - item['ai_ref'] = ''
   - item['is_th'] = False
   - item['qa_failed'] = False
   - แถวจะเปลี่ยนสถานะในตารางกลับเป็น **'รอแปล' (Untranslated)**
2. **AI Draft Only (only_ai=True)**:
   - item['ai_ref'] = ''
   - คง 	rans เดิมไว้ไม่ให้กระทบข้อความที่แปลเสร็จแล้ว

## 3. จุดเข้าถึงฟังก์ชันบน UI (UI Access Points)

| จุดควบคุม (UI Location) | ปุ่ม / เมนู | คีย์ลัด | คำอธิบายการทำงาน |
| :--- | :--- | :--- | :--- |
| **Col 3 Sub-Action Bar** | 🧹 ลบคำแปล ▾ | — | Dropdown เลือกล้างเฉพาะแถว หรือล้างทั้งหมดในไฟล์ |
| **Col 3 Sub-Action Bar** | 🗑️ ลบแถว | — | ลบแถวออกจากไฟล์อย่างถาวร (มีกล่องยืนยัน) |
| **ตารางแปลภาษา** | กดปุ่มคีย์บอร์ด | Backspace | ลบคำแปลแถวที่ไฮไลต์กลับเป็นรอแปลทันที |
| **ตารางแปลภาษา** | กดปุ่มคีย์บอร์ด | Delete | เปิดกล่องถามว่าจะ 'ลบแถวออกจากไฟล์' หรือ 'ลบเฉพาะคำแปล' |
| **Floating Action Bar** | 🧹 ลบคำแปล | — | แถบลอยที่ปรากฏเมื่อคลุมเลือกหลายแถว ล้างคำแปลแถวที่เลือก |
| **คลิกขวาตาราง** | Context Menu | — | เมนูคลิกขวาสะดวกสำหรับลบคำแปล หรือลบทั้งหมด |
| **เมนูบาร์ด้านบน** | แก้ไข (Edit) | — | รวมคำสั่งลบคำแปลทุกระดับ |
| **TRun Studio Banner** | 🧹 ลบคำแปลทั้งหมด... | — | ปุ่มล้างคำแปลทั้งไฟล์บนหน้า TRun ก่อนเริ่มรัน Batch |

## 4. กล่องยืนยันความปลอดภัย (Safety Dialogs)

เมื่อผู้ใช้กด **'ลบคำแปลทั้งหมดในไฟล์ (Clear All Translations)'**:
1. ระบบจะคำนวณจำนวนแถวที่มีคำแปลจริง หากเป็น 0 จะแจ้งว่าไม่มีคำแปลที่ต้องลบ
2. แสดงกล่องคำถาม QMessageBox.question ระบุ:
   - จำนวนบรรทัดที่มีคำแปลปัจจุบัน
   - ยืนยันว่าข้อความต้นฉบับภาษาอังกฤษและ ID จะคงอยู่ปลอดภัย 100%
   - ช่อง 'คำแปลภาษาไทย' และ 'แปลโดย AI' ทั้งหมดจะถูกล้างกลับเป็น 'รอแปล'
3. ปุ่มเริ่มต้นถูกตั้งค่าเป็น No เพื่อป้องกันการกด Enter ผิดพลาด
