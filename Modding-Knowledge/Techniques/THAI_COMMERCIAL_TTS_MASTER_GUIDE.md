# คัมภีร์ระบบสร้างเสียงพากย์ขายสินค้าภาษาไทย (Thai Commercial TTS Master Bible)
**คู่มือระบบสร้างเสียงภาษาไทยระดับมนุษย์ (SOTA Neural Flow-Matching) พร้อมระบบฟังตัวอย่างเสียงก่อนเลือก**

---

## 1. ภาพรวมระบบ (System Architecture)

ระบบ **Thai Commercial TTS** ได้รับการยกเครื่องและอัปเกรดครั้งใหญ่จากระบบเดิมที่เป็นเสียงสังเคราะห์แบบหุ่นยนต์ (Edge-TTS) ก้าวขึ้นสู่สถาปัตยกรรม **SOTA Neural Flow-Matching (F5-TTS Thai)** ที่มีความฉลาดในการออกเสียง วรรคตอน ลมหายใจ และโทนเสียงระดับคนจริงพูด โดยรันฟรีบน GPU ประจำเครื่อง (RTX 4070 บน AiPC1 หรือ RTX 4080S บน Main PC)

```
[ ผู้ใช้ป้อนข้อความภาษาไทย ]
          │
          ▼
[ เลือกผู้พูดจาก 8 สไตล์มืออาชีพ ] ──▶ [ 🔊 กดฟังเสียงตัวอย่างได้ทันทีใน ComfyUI Canvas ]
          │
          ▼
[ F5-TTS Thai Neural Engine ] ──▶ ดึง Voice Reference Profile (24kHz WAV)
          │
          ├──▶ AiPC1 (RTX 4070) ใช้เวลาประมวลผลเพียง ~2.3 วินาที
          │
          ▼
[ Output สมบูรณ์แบบ ]
   ├── ComfyUI Node Canvas (ฟังเสียง & โหลด MP3 ทันที)
   └── บันทึกอัตโนมัติลง NAS: Z:\05_VideoFootage\01_ComfyUi_Footage\03_Audio\Voiceovers\
```

## 4. เวิร์กโฟลว์ ComfyUI ที่เรียบง่ายที่สุด (Minimalist 2-Node Canvas)

ไฟล์เวิร์กโฟลว์: `Z:\01_Work\01_ComfyUi_Project\01_AI_Short_Drama_Engine\Thai_TTS_Simple.json`

### องค์ประกอบของหน้าจอ:
1. **โหนดที่ 1: `ThaiCommercialTTS`**
   - **Text**: กล่องใส่ข้อความภาษาไทย (รองรับข้อความยาว ระบบตัดคำให้อัตโนมัติ)
   - **Voice Preset**: เลือก 1 ใน 8 ผู้พูด
   - **Engine**: ค่าเริ่มต้นเป็น `⚡ F5-TTS Thai (SOTA Neural Voice)`
   - **Speed**: แถบปรับความเร็วเสียง (0.5 – 2.0, ค่าปกติ 1.0)
   - **Tone Pitch**: ปรับความเข้มข้น/อารมณ์เสียง (-10 ถึง +10)
   - **ปุ่ม `🔊 ฟังเสียงตัวอย่าง`**: กดฟังเสียงตัวอย่างของผู้พูดที่เลือก
2. **โหนดที่ 2: `SaveAudioMP3`**
   - แสดงเครื่องเล่นเสียงผลลัพธ์พร้อมคลื่นเสียง (Waveform Player)
   - บันทึกไฟล์ MP3 อัตโนมัติ
