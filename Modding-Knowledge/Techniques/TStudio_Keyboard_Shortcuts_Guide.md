# คู่มือคีย์ลัดและการจัดการคำสั่งใน TStudio (TStudio Universal Keyboard Shortcuts Guide)

เอกสารนี้รวบรวมรายการคีย์ลัดทั้งหมดของ **TStudio (Translation Studio)** ที่ได้รับการปรับปรุงใหม่ ขจัดปัญหาคีย์ชนกัน (Ambiguous Overload) และจัดสรรตามหลักสากลของการพัฒนาเครื่องมือ CAT Tool และ Game Localization

---

## 1. รายการคีย์ลัดทั้งหมดแยกตามหมวดหมู่

### 📁 การจัดการไฟล์และโปรเจกต์ (File & Project)
| คีย์ลัด | ฟังก์ชันการทำงาน | คำอธิบาย |
| :--- | :--- | :--- |
| **Ctrl+N** | เริ่มแปลไฟล์ใหม่ / นำเข้าไฟล์แปล | เรียกหน้าต่างเริ่มโปรเจกต์ใหม่จากไฟล์ภาษาต้นฉบับ |
| **Ctrl+O** | เปิดโปรเจกต์แปล / เปิดไฟล์อื่น | เลือกเปิดไฟล์งานเดิมหรือโปรเจกต์ที่เคยทำไว้ |
| **Ctrl+S** | บันทึกข้อมูล (Save) | บันทึกการเปลี่ยนแปลงลงไฟล์ CSV ปัจจุบันทันที |
| **Ctrl+Shift+S** | บันทึกเป็นไฟล์ใหม่ (Save CSV As...) | ส่งออกหรือบันทึกไฟล์เป็นชื่อใหม่ |
| **Ctrl+D** | ติดตั้งเข้าเกมทันที (Deploy to Game) | แปลงและประกอบไฟล์ส่งเข้าโฟลเดอร์ Mod ของเกม |

### 🤖 การแปลภาษาและ AI (Translation & AI)
| คีย์ลัด | ฟังก์ชันการทำงาน | คำอธิบาย |
| :--- | :--- | :--- |
| **Ctrl+T** | แปลอัจฉริยะ (Smart AI Retranslate) | แปลแถวปัจจุบันด้วยโมเดลที่เลือก (หรือแปลเป็นกลุ่มหากเลือกหลายแถว) |
| **Ctrl+Shift+T** | แปลเฉพาะคำ/วลีที่ไฮไลต์ (Selected Snippet) | ส่งแปลเฉพาะคำที่ลากคุมในช่องแปลหรือต้นฉบับ โดยรักษาบริบททั้งประโยค |
| **Ctrl+Shift+Y** | แปลทับศัพท์เฉพาะส่วนที่ไฮไลต์ (Transliterate) | แปลทับศัพท์ (Phonetic Transliteration) ตามเสียงอ่าน เหมาะกับชื่อคน สกิล ไอเทม |
| **Ctrl+Shift+O** | แปลเปรียบเทียบ 3 รูปแบบ (3 Styles) | ส่งคำสั่งให้ AI ให้ผลลัพธ์ 3 ทางเลือก (กระชับ, วรรณกรรม, ทางการ) |
| **Ctrl+Shift+B** | รันแปลอัตโนมัติทั้งชุด (Batch Retranslate) | สั่งรัน AI แปลแถวที่คัดเลือกทั้งหมดแบบ Background |
| **Ctrl+1** | เลือกผลแปล AI สไตล์ที่ 1 | นำข้อความจากตัวเลือกสไตล์ที่ 1 มาใส่ในกล่องข้อความแปล |
| **Ctrl+2** | เลือกผลแปล AI สไตล์ที่ 2 | นำข้อความจากตัวเลือกสไตล์ที่ 2 มาใส่ในกล่องข้อความแปล |
| **Ctrl+3** | เลือกผลแปล AI สไตล์ที่ 3 | นำข้อความจากตัวเลือกสไตล์ที่ 3 มาใส่ในกล่องข้อความแปล |
| **Ctrl+Enter / Enter** | ยืนยันและข้ามไปยังแถวถัดไป | บันทึกแถวปัจจุบันและเลื่อนแถวในตารางไปยังบรรทัดถัดไปทันที |
| **Shift+Enter** | ขึ้นบรรทัดใหม่ในช่องแปล | เพิ่มบรรทัดใหม่ (Newline) ในช่องพิมพ์คำแปลโดยไม่ข้ามแถว |

### 📝 การแก้ไขและค้นหา (Editing & Search)
| คีย์ลัด | ฟังก์ชันการทำงาน | คำอธิบาย |
| :--- | :--- | :--- |
| **Ctrl+F** | โฟกัสช่องค้นหาด่วน (Focus Quick Search) | ย้ายเคอร์เซอร์ไปยังช่องค้นหาด่วนของตารางทันที |
| **Alt+C** | เปิด/ปิด ค้นหาตรงตามตัวพิมพ์ใหญ่-เล็ก (Match Case) | แยกแยะ `e` เล็ก กับ `E` ใหญ่ |
| **Alt+W** | เปิด/ปิด ค้นหาตรงทั้งคำ (Match Whole Word) | ค้นหาเฉพาะคำเดี่ยวๆ ไม่รวมคำที่มีตัวอักษรนี้แฝงอยู่ (เช่น ไม่รวม `the`, `enter`) |
| **Alt+E** | เปิด/ปิด ค้นหาตรงทั้งประโยคเป๊ะๆ (Exact Match) | ค้นหาแถวที่มีข้อความตรงเป๊ะๆ เช่น `e` ตัวเดียวล้วนๆ (หรือพิมพ์นำหน้าด้วย `=e`) |
| **Alt+R** | เปิด/ปิด โหมดนิพจน์เรกูลาร์ (Regular Expression) | ค้นหาด้วย Regular Expression รองรับ regex syntax ชั้นสูง |
| **Ctrl+H** | เปิดหน้าต่างค้นหาและแทนที่คำ | เปิดกล่องค้นหาและ Find & Replace คำแปลทั่วทั้งไฟล์ (รองรับทั้ง Case, Whole Word, Exact) |
| **Ctrl+Z** | ยกเลิกการกระทำล่าสุด (Undo) | ย้อนกลับการพิมพ์หรือการแก้ไขล่าสุด |
| **Ctrl+Y** | ทำซ้ำการกระทำ (Redo) | ทำซ้ำสิ่งที่ถูกยกเลิกไป |
| **Ctrl+X / Ctrl+C / Ctrl+V** | ตัด / คัดลอก / วาง | คำสั่งมาตรฐานของระบบปฏิบัติการ |

## 2. หลักการทางเทคนิคในการป้องกันคีย์ลัดชนกัน (Technical Resolution)

1. **การแยกคีย์ระหว่าง Menu Actions และ QShortcut**:
   - แยก Ctrl+N ให้กับการสร้างโปรเจกต์ และให้ Ctrl+Shift+O ทำหน้าที่แปล 3 ทางเลือก
   - ย้าย Ctrl+Return และ Ctrl+Enter ออกจาก 
etranslate_smart ให้มีเฉพาะ Ctrl+T ทำให้ Ctrl+Enter ถูกสงวนไว้สำหรับการบันทึกและไปแถวถัดไป 100%
   - เปลี่ยนคีย์ลัดเปิด/ปิดคอลัมน์จาก Ctrl+1/2/3 เป็น Alt+1/2/3 เพื่อไม่ให้ชนกับการเลือกสไตล์ผลแปล AI (Ctrl+1/2/3)
   - แยก Ctrl+F (โฟกัสแถบค้นหาด่วน) และ Ctrl+H (เปิด Find & Replace) ตามมาตรฐานสากล
2. **การจำกัดขอบเขต Context (Widget-Scoped Shortcuts)**:
   - กำหนด Qt.ShortcutContext.WidgetWithChildrenShortcut ให้กับ Delete, Shift+Delete, และ Backspace บนตารางหลัก เพื่อให้ผู้ใช้สามารถกดปุ่ม Delete หรือ Backspace ภายในช่องพิมพ์ข้อความแปลหรือช่องค้นหาได้ตามปกติ โดยไม่เผลอไปลบแถวในตาราง
3. **Idempotency ใน Menu Bar Registration**:
   - จดบันทึกและล้าง _window_shortcut_actions ก่อนสร้างเมนูบาร์ใหม่ทุกครั้ง ป้องกันไม่ให้เกิด Action ซ้ำซ้อนสะสมบน Main Window เมื่อผู้ใช้สลับโหมดไปมา
