# คู่มือการแปลเฉพาะส่วนและแปลทับศัพท์ใน TStudio (Snippet Translation & Transliteration Guide)

เอกสารฉบับนี้อธิบายฟังก์ชัน **การแปลเฉพาะส่วน (Snippet Translation)** และ **การแปลทับศัพท์ (Phonetic Transliteration)** ใน **TStudio** เพื่อให้นักแปลเกมสามารถแปลหรือถอดเสียงคำศัพท์เฉพาะ ชื่อตัวละคร ไอเทม สกิล และสถานที่ได้อย่างแม่นยำ รวดเร็ว โดยไม่ต้องแปลใหม่ทั้งประโยค

---

## 1. ฟังก์ชันการทำงานหลัก (Key Features)

1. **Floating Quick Action Pill (แถบปุ่มลอยอัจฉริยะ)**:
   - เมื่อลากเมาส์ไฮไลต์ (Select) คำหรือวลีในช่อง **3. คำแปลของฉัน (`txt_trans`)** หรือ **1. ข้อความต้นฉบับ (`txt_source`)** แถบปุ่มลอยจะปรากฏเหนือตำแหน่งเคอร์เซอร์โดยอัตโนมัติ
   - ปุ่มบนแถบประกอบด้วย:
     - `✨ แปลคำนี้` (`#btnTransPill` สีฟ้าคราม): แปลคำที่เลือกตามบริบทของประโยค
     - `🗣️ ทับศัพท์` (`#btnTranslitPill` สีเขียวมินต์): แปลงเสียงอ่านเป็นภาษาไทย (Phonetic Transliteration) โดยไม่แปลความหมายตรงตัว
     - `💡 3 สไตล์` (`#btnStylesPill` สีส้มพีช): ขอ 3 สไตล์การแปล (ตรงตัว, ภาษาพูด, ทางการ) ให้เลือกกดนำไปใช้งาน
     - `✕` (`#btnClosePill`): ปิดแถบลอยชั่วคราว

2. **คีย์ลัดเฉพาะ (Dedicated Shortcuts)**:
   - `Ctrl+Shift+T`: สั่งแปลคำที่ไฮไลต์ทันที
   - `Ctrl+Shift+Y`: สั่ง **แปลทับศัพท์** คำที่ไฮไลต์ทันที
   - `Ctrl+Enter`: บันทึกคำแปลและเลื่อนไปยังแถวถัดไป

3. **เมนูคลิกขวา (Right-Click Context Menus)**:
   - คลิกขวาบนข้อความที่เลือกใน **ช่องคำแปล (`txt_trans`)**:
     - `✨ แปลเฉพาะคำนี้: "..." (Ctrl+Shift+T)`
     - `🗣️ แปลทับศัพท์เฉพาะคำนี้: "..." (Ctrl+Shift+Y)`
     - `💡 แปล 3 สไตล์สำหรับคำนี้...`
     - `📖 บันทึก "..." ลง Glossary...`
   - คลิกขวาบนข้อความที่เลือกใน **ช่องต้นฉบับ (`txt_source`)**:
     - `✨ แปลคำนี้ -> ใส่ในช่องแปล: "..."`
     - `🗣️ ทับศัพท์คำนี้ -> ใส่ในช่องแปล: "..." (Ctrl+Shift+Y)`
     - `💡 แปล 3 สไตล์สำหรับคำนี้...`
   - คลิกขวาบนข้อความใน **ช่องผลแปล AI (`txt_ai`)**:
     - `⬇ นำส่วนที่เลือกไปใส่ในช่องแปล: "..."`
     - `🗣️ แปลทับศัพท์ส่วนนี้ -> ใส่ในช่องแปล: "..."`

4. **เมนูแปลพิเศษและปุ่ม ⚙️ ▾ (`special_menu`)**:
   - เพิ่มตัวเลือก `🗣️ แปลทับศัพท์เฉพาะส่วนที่เลือก (Ctrl+Shift+Y)`
   - หากผู้ใช้เลือกคำสั่งใดๆ ในเมนูพิเศษ (เช่น ทับศัพท์, สำนวน, บทกวี, วัยรุ่น) ขณะมีข้อความถูกไฮไลต์ ระบบจะแปลเฉพาะส่วนที่เลือกโดยอัตโนมัติ

## 2. หลักการวิศวกรรม Prompt การแปลทับศัพท์ (Prompt Engineering)

เมื่อผู้ใช้เลือกโหมด **ทับศัพท์ (Transliteration)**:
- ระบบจะส่งเฉพาะคำที่เลือก พร้อมบริบทของแถว (Context ID, Category Tag, ประโยคต้นฉบับเต็ม และคำแปลที่กำลังพิมพ์อยู่) ไปยัง AI
- คำสั่งสั่งห้ามแปลความหมายเชิงอรรถศาสตร์ (Semantic Translation) อย่างเด็ดขาด เช่น:
  - `Shadow` ➔ แปลงเป็น `แชโดว์` (ไม่ใช่ "เงา")
  - `Blacksmith` ➔ แปลงเป็น `แบล็กสมิธ` (ไม่ใช่ "ช่างตีเหล็ก")
  - `Hunter` ➔ แปลงเป็น `ฮันเตอร์` (ไม่ใช่ "นายพราน")
  - `Citadel` ➔ แปลงเป็น `ซิตาเดล` (ไม่ใช่ "ป้อมปราการ")
- รองรับหลักการถอดเสียงตามราชบัณฑิตยสภาและแนวทางสากลของวงการแปลเกมไทย (เช่น ตัวสะกด การใช้ทัณฑฆาต ์)
- ป้องกันการแทนที่ด้วยคำแปลทั่วไปจาก Glossary หากคำนั้นไม่ใช่การทับศัพท์ที่ตั้งใจไว้

## 3. ตัวอย่างการใช้งานจริง (Use Cases)

| คำต้นฉบับ | โหมดแปลปกติ (`✨ แปลคำนี้`) | โหมดทับศัพท์ (`🗣️ ทับศัพท์`) | ประโยชน์ในเกม |
| :--- | :--- | :--- | :--- |
| **Reaper** | ผู้เก็บเกี่ยว / มัจจุราช | **รีปเปอร์** | ใช้เป็นชื่อคลาส, ฉายาตัวละคร หรือชื่อบอส |
| **Workshop** | โรงซ่อม / เวิร์กช็อป | **เวิร์กชอป** | ชื่อสถานที่หรือเมนูคราฟต์ของ |
| **Stalker** | ผู้สะกดรอย | **สตอล์กเกอร์** | ชื่อมอนสเตอร์ประเภทลอบเร้น |
| **Ranger** | พรานป่า / หน่วยลาดตระเวน | **เรนเจอร์** | ชื่ออาชีพ/คลาสตัวละคร |
| **Sanctuary** | เขตศักดิ์สิทธิ์ / ที่ลี้ภัย | **แซงก์ทัวรี** | ชื่อแผนที่หรือเซฟโซน |
