# คู่มือการแปลเกมจากภาษาต้นฉบับหลากหลาย (Multilingual Source Game Localization Guide)
*ครอบคลุมภาษาต้นฉบับ: ญี่ปุ่น (Japanese), จีน (Chinese), เกาหลี (Korean), ยุโรป (European) และ อังกฤษ (English)*
*สำหรับ TStudio, THub และระบบแปลภาษาใน Modder Hub Ecosystem*

---

## 1. ที่มาและปัญหาเดิม (The Root Cause)

เมื่อม็อดเดอร์นำไฟล์แปลที่มี **ภาษาต้นฉบับเป็นภาษาญี่ปุ่น (日本語), ภาษาจีน (中文), ภาษาเกาหลี (한국어)** หรือภาษาอื่นๆ ที่ไม่ใช่ภาษาอังกฤษ เข้ามาแปลใน TStudio แล้วพบว่า:
- **กดแปลเดี่ยว (Smart / AI Translate)**: ขึ้นข้อความแถบสถานะว่า `"Skipped — text is tags/symbols only."` หรือ `"⏭️ ข้ามการแปล: ข้อความไม่มีเนื้อหาที่ต้องแปล"` โดยไม่ยอมส่งไปแปลที่ AI เลย
- **กดแปล 3 สไตล์ (Options)**: ขึ้นข้ามการแปลเช่นเดียวกัน
- **กดแปลชุดใหญ่ (Batch Translation)**: ระบบคัดลอกข้อความภาษาญี่ปุ่น/จีนต้นฉบับลงไปในช่องคำแปลทันที โดยไม่ยิง API ไปหา AI

### สาเหตุทางเทคนิค (The Technical Cause)
ในอดีต TStudio มีฟังก์ชันกรองความปลอดภัย `CoreAI.should_skip_translation(source_text)` ใน `tstudio_core.py` เพื่อป้องกันไม่ให้ส่งข้อความที่เป็น "ตัวเลขล้วน" (เช่น `12345`) หรือ "แท็กโค้ดเกมเปล่าๆ" (เช่น `<Header_01>`, `{player_name}`) ไปเปลืองโควตา Token ของ AI

เดิมทีตัวกรองนี้ใช้ Regular Expression ตรวจจับตัวอักษรเฉพาะย่าน:
```python
# โค้ดเดิมที่มีปัญหา
if not re.search(r'[a-zA-Z\u0E00-\u0E7F]', text_no_tags):
    return True  # ข้ามการแปลทันที!
```
- ตัวกรองนี้ตรวจจับเฉพาะ **ภาษาอังกฤษ (`a-zA-Z`)** และ **ภาษาไทย (`\u0E00-\u0E7F`)** เท่านั้น
- เมื่อข้อความต้นฉบับเป็นภาษาญี่ปุ่น (ฮิรางานะ `\u3040-\u309F`, คาตาคานะ `\u30A0-\u30FF`, คันจิ `\u4E00-\u9FFF`) หรือภาษาจีน ระบบจึงหาตัวอักษร `a-z` ไม่พบ
- ระบบจึงสรุปผิดพลาดว่า "ข้อความนี้มีแต่สัญลักษณ์/แท็กเปล่า ไม่มีเนื้อหาให้แปล" แล้วสั่ง **Skip อัตโนมัติ**

นอกจากนี้ ในฟังก์ชัน `clean_ai_translation` เดิมมีระบบตัดคำหลอน (Hallucination Check) ที่คำนวณจากความยาวของตัวอักษร:
```python
# โค้ดเดิม
if len(source_text) <= 15:
    if len(cleaned) >= 20 and len(cleaned) > len(source_text) * 4:
        return source_text  # ตัดคำแปลทิ้งแล้วคืนค่าเดิม!
```
- ในภาษาจีน/ญี่ปุ่น คำสั้นๆ เพียง 2-4 ตัวอักษร (เช่น `設定` = 2 ตัวอักษร, `自動保存中` = 5 ตัวอักษร) สามารถแปลเป็นภาษาไทยได้ยาวถึง 15-25 ตัวอักษร (`การตั้งค่าระบบ`, `กำลังบันทึกข้อมูลอัตโนมัติ`) ซึ่งเกินเกณฑ์ `4x` ทำให้ระบบเดิมเข้าใจผิดว่าเป็น AI หลอน แล้วลบคำแปลทิ้ง

## 2. โครงสร้างการแก้ไขใหม่ (The Universal Multilingual Engine)

### 2.1 ระบบตรวจจับตัวอักษรสากล (Universal Unicode Letter Classification)
อัปเกรด `CoreAI.should_skip_translation` ใน `tstudio_core.py` ให้ใช้มาตรฐานหมวดหมู่อักขระสากล (Unicode Character Database - `unicodedata`):

```python
import unicodedata

# ดึงแท็กโค้ดเกมออกก่อน (<...>, {...}, [...])
text_no_tags = re.sub(r'<[^>]*>', '', source_text)
text_no_tags = re.sub(r'\{[^}]*\}', '', text_no_tags)
text_no_tags = re.sub(r'\[[^\]]*\]', '', text_no_tags)
text_no_tags = text_no_tags.strip()

# ตรวจสอบว่ามีตัวอักษรของมนุษย์ (Letter categories: Lu, Ll, Lt, Lm, Lo) หรือไม่
has_letters = any(unicodedata.category(c).startswith('L') or c.isalpha() for c in text_no_tags)
if not has_letters:
    return True  # ข้ามเฉพาะบรรทัดที่เป็นตัวเลข/สัญลักษณ์ล้วนจริงๆ
```

#### ผลลัพธ์จากการทดสอบ (Verification Matrix):
| ตัวอย่างข้อความ | ภาษา / ประเภท | พฤติกรรมเดิม | พฤติกรรมใหม่ |
| :--- | :--- | :--- | :--- |
| `「こんにちは、世界！」` | ญี่ปุ่น (Hiragana/Kanji) | ❌ โดน Skip | ✅ ส่งแปลปกติ |
| `【任务完成】` | จีน (Hanzi) | ❌ โดน Skip | ✅ ส่งแปลปกติ |
| `안녕하세요` | เกาหลี (Hangul) | ❌ โดน Skip | ✅ ส่งแปลปกติ |
| `Привет, мир!` | รัสเซีย (Cyrillic) | ❌ โดน Skip | ✅ ส่งแปลปกติ |
| `Épée enchantée` | ฝรั่งเศส (Accented Latin) | ❌ เสี่ยงหลุด | ✅ ส่งแปลปกติ |
| `Hello World` | อังกฤษ (ASCII) | ✅ ส่งแปลปกติ | ✅ ส่งแปลปกติ |
| `<Header_NPC>{100}` | แท็กโค้ดล้วน | ✅ โดน Skip | ✅ ข้ามอัตโนมัติ (ถูกต้อง) |
| `100 / 200` | ตัวเลขและสัญลักษณ์ล้วน | ✅ โดน Skip | ✅ ข้ามอัตโนมัติ (ถูกต้อง) |
| `Lv. 99` หรือ `HP +100` | ตัวเลขผสมชื่อย่อ | ✅ ส่งแปลปกติ | ✅ ส่งแปลปกติ |

### 2.2 ระบบตรวจจับคำหลอนที่ปรับแต่งตามความหนาแน่นอักขระ (CJK-Aware Hallucination Guard)
ใน `clean_ai_translation`:
- ตรวจจับว่าข้อความต้นฉบับมีอักขระ CJK หรือไม่ (`RE_CJK` หรือ `\u3040-\u30ff` หรือ `\uac00-\ud7af`)
- สำหรับภาษา CJK: อนุญาตให้คำแปลภาษาไทยมีความยาวได้มากกว่าตามธรรมชาติของภาษา (เช่น ตัวอักษรญี่ปุ่น 2 ตัวแปลไทย 20 ตัวได้ตามปกติ) โดยจะตัดทิ้งเฉพาะกรณีที่ยาวผิดปกติเกินจริง (AI เขียนบทความอธิบายขนาดยาวเกิน 45 ตัวอักษรและมากกว่าต้นฉบับ 10 เท่า)
- สำหรับภาษาที่มีตัวอักษรละติน/อังกฤษ: ยังคงใช้เกณฑ์ความปลอดภัยมาตรฐานเดิม

---

### 2.3 ปรับ System Prompt ให้เป็นสากล (Multilingual Localization Directives)
ปรับปรุง Prompt ทั้งใน `tstudio_core.py`, `tstudio_app.py`, และ `tstudio_tlm_studio.py`:
- เดิม: `"You are a Master-Level English-to-Thai Video Game Localization Specialist."`
- ใหม่: `"You are a Master-Level Video Game Localization Specialist translating the source language into natural Thai."`
- กฎความบริสุทธิ์ของภาษา (Language Purity):
  - ระบุชัดเจนว่า **ห้ามมีตัวอักษรภาษาต้นฉบับ, ภาษาจีน (汉字), หรือภาษาญี่ปุ่นหลุดรอดมาใน "ผลลัพธ์คำแปลภาษาไทย" (Thai Translation Output)**
  - ทำให้ AI เข้าใจได้ถูกต้องว่า "อ่านภาษาต้นฉบับได้ทุกภาษา แต่เมื่อส่งออกเป็นภาษาไทย ต้องเป็นภาษาไทย 100%"

## 3. การเชื่อมโยงกับ THub (`thub_project.json`) และ Profiles

### ผู้ใช้ถาม: *"ตอนที่ THub กำหนดตอนแรก นั้นส่งผลต่อโปรไฟล์ไหม หรือโปรไฟล์มีรูปแบบกดเฉพาะ?"*

1. **การตั้งค่าใน THub**:
   - เมื่อสร้างโปรเจกต์ใหม่ใน THub จะมีช่องเลือก **Source Language** (เช่น English, Japanese, Chinese, etc.)
   - ค่านี้จะถูกบันทึกไว้ใน `thub_project.json` (เช่น `"source_lang": "Japanese"`)
   - THub บันทึกข้อมูลนี้ไว้เป็น Metadata ประจำโปรเจกต์อย่างถูกต้อง

2. **โปรไฟล์ของ TStudio**:
   - โปรไฟล์ (Profile) ใน TStudio (เก็บใน `prompts.json`) คือ **ชุดแม่แบบคำสั่งและ Glossaries ที่กำหนดสไตล์การแปล** (เช่น แฟนตาซี, ไซไฟ, สรรพนาม)
   - **ไม่มีรูปแบบการกดปุ่มเฉพาะ หรือลำดับกดผิดที่ทำให้แปลไม่ได้**: ปัญหาเดิมเกิดจาก Bug ภายในตัวกรองความปลอดภัย `should_skip_translation` ที่บล็อกข้อความที่ไม่ใช่ภาษาอังกฤษเท่านั้น
   - หลังจากการอัปเดตนี้: **ไม่ว่าคุณจะเลือกภาษาอะไรใน THub หรือเปิดไฟล์เกมภาษาญี่ปุ่น/จีนตรงๆ เข้าสู่ TStudio ระบบจะปลดล็อกให้แปลได้ทันทีทุกปุ่ม (แปลเดี่ยว, แปล 3 สไตล์, แปลทั้งชุด)**

## 4. ข้อแนะนำและเคล็ดลับในการแปลเกมภาษาญี่ปุ่น/จีน

1. **การจับคู่สรรพนามใน TLM Studio**:
   - ภาษาญี่ปุ่นมีการใช้สรรพนามหลากหลาย (เช่น `私` (Watashi), `俺` (Ore), `僕` (Boku), `貴様` (Kisama), `お前` (Omae))
   - ใน TLM Studio สามารถเลือกชุดสรรพนามตามสไตล์เกมได้ เช่น:
     - เกมแนวอนิเมะ/ผจญภัย: ใช้ `ฉัน - นาย`, `ผม - เธอ`
     - เกมซามูไร/ย้อนยุค: ใช้ `ข้า - เจ้า`, `ข้า - ท่าน`
2. **การป้องกันคำเฉพาะ (Glossary Protection)**:
   - สำหรับภาษาญี่ปุ่น/จีน สามารถเพิ่มคำศัพท์ใน **Terminology & Glossary Editor** ในรูปแบบ `[คำญี่ปุ่น] = [คำแปลไทย]` ได้โดยตรง
   - เช่น `ポーション = โพชั่น`, `勇者 = ผู้กล้า`, `スライム = สไลม์`
3. **การตรวจสอบ CJK Leak**:
   - เมื่อแปลเสร็จแล้ว สามารถใช้ฟิลเตอร์แถบสถานะด้านบนของ TStudio เลือกดู **"🇨🇳 มีภาษาจีน/CJK หลุดมา"** เพื่อสแกนหาข้อความที่อาจมีอักขระคันจิหลงเหลืออยู่ในช่องคำแปลไทยได้อย่างแม่นยำ
