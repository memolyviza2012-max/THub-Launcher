# 🎨 เอกสารร่างการออกแบบ UX/UI ใหม่ทั้งหมด: TStudio Next-Gen

## 1. บทนำและวิสัยทัศน์ (Vision & Objectives)

![TStudio Next-Gen UI Design Mockup](docs/images/tstudio_redesign_ui_1789045944978.jpg)

**TStudio** เป็นเครื่องมือแปลภาษาเกมระดับ Flagship ที่มีฟีเจอร์ทรงพลังมากมาย (การเชื่อมต่อโมเดล AI ล่าสุด, การกรอง CJK Leak, QA Check, PUA Tagging, Multi-row Deletion ฯลฯ) 

อย่างไรก็ตาม หน้าตาโปรแกรมในปัจจุบันสร้างขึ้นด้วยระบบ **Multi-Dock แยกชิ้นส่วน** ซึ่งมีจุดอ่อนสำคัญ:
* **ความกระจัดกระจาย (Fragmentation)**: หน้าต่างแยกเป็น 4-5 Dock ย่อย (Dock ตาราง, Dock ต้นฉบับ, Dock คำแปล, Dock คลังศัพท์) ทำให้สายตาของผู้แปลต้องกวาดไปมาหลายทิศทาง
* **ความแออัดของปุ่ม (Button Clutter)**: ปุ่มหลากสีเรียงกันเป็นพรืดในแถบเครื่องมือ ทำให้ดูรกและไม่รู้ว่าปุ่มไหนสำคัญที่สุดในสถานการณ์ใด
* **ขาดความรู้สึกร่วมสมัย (Modern CAT Tool Feeling)**: โปรแกรมแปลภาษาระดับโลกในปัจจุบัน (เช่น DeepL Pro, Smartcat, Crowdin, หรือ Cursor IDE) ล้วนใช้แนวคิด **"Active Segment Focus"** คือรวมทุกอย่างที่จำเป็นสำหรับประโยคที่กำลังแปลมาไว้ที่จุดเดียว

**เป้าหมายการออกแบบใหม่ (Redesign Goals)**:
1. **Ergonomic 3-Zone Layout**: แบ่งพื้นที่ชัดเจน ไม่หลุดตำแหน่ง สบายตา
2. **Speed & Keyboard-First**: ม็อดเดอร์พิมพ์แปลได้ลื่นไหล ไม่ต้องเอื้อมเมาส์บ่อย
3. **AI Copilot Deck**: นำเสนอคำแปล 3 สไตล์จาก AI ให้เลือกใช้ใน 1 คลิก หรือกด `Ctrl+1/2/3`
4. **In-Context Glossary Chips**: คำศัพท์ที่ตรงกับประโยคปัจจุบันจะเด้งขึ้นมาเป็นป้ายให้คลิกแทรกได้ทันที
5. **Floating Bulk Action Bar**: แถบควบคุมลอยตัวที่ฉลาด จะปรากฏขึ้นมาเมื่อลากคลุมหลายแถว

## 2. ตารางเปรียบเทียบ: ปัญหาเดิม vs การออกแบบใหม่

| มิติการใช้งาน | ปัญหาใน UI เดิม (Current) | โซลูชันใน UI ใหม่ (Next-Gen) |
|---|---|---|
| **โครงสร้างหน้าจอ** | หน้าต่าง Dock หลุดแยกชิ้น ย้ายแล้วจัดกลับยาก | **3-Zone Split Canvas**: แถบหัวคุมสถานะ, ตารางนำทางฝั่งซ้าย (52%), แท่นแปลฝั่งขวา (48%) ล็อคสัดส่วนสวยงาม |
| **การมองเห็น & โฟกัส** | สายตาต้องมองสลับ 4 จอ (ตาราง ➔ ต้นฉบับ ➔ คำแปล ➔ คำศัพท์) | **Active Row Workbench**: รวมข้อความต้นฉบับ + กล่องคำแปล + ชิปคำศัพท์ + คำแนะนำ AI ไว้ในการกวาดสายตาครั้งเดียว |
| **ปุ่มสั่งการ AI** | ปุ่มเมนูย่อยเยอะ กระจายหลายสี ปรับแต่งยาก | **AI Copilot Deck**: การ์ด 3 สไตล์ (สไตล์เกม, ทางการ, สบายๆ) พร้อมปุ่มลัด `Ctrl+1..3` กด `Enter` เพื่อนำไปใช้ทันที |
| **การใช้คำศัพท์ (Glossary)** | ต้องเปิด Dock คำศัพท์ยาวเหยียดแล้วกวาดหาเอง | **Smart Chips**: ตรวจจับคำศัพท์ในประโยคปัจจุบันให้อัตโนมัติ แสดงเป็นชิปใต้ประโยค คลิกเพื่อแทรกคำแปลลงช่องพิมพ์ได้ทันที |
| **การจัดการหลายแถว** | คีย์ลัดจำยาก ไม่มีแถบแจ้งเตือนจำนวนที่เลือก | **Floating Action Bar**: เมนูลอยตัวตรงกลางตาราง แจ้งจำนวนแถวที่เลือก พร้อมปุ่ม `⚡ แปล AI`, `🇨🇳 ล้างจีน`, `🗑️ ลบทิ้ง` ชัดเจน |

## 4. รายละเอียดแต่ละโซน (Deep Dive Specifications)

### 🌟 โซนที่ 1: Top App Bar (ศูนย์รวมสถานะ)
* **Project Badge**: แสดงชื่อไฟล์และไอคอนโปรเจกต์
* **Engine Status Pill**: แสดงสถานะ AI ปัจจุบัน เช่น `[🟢 DeepSeek-V3 ▾]` หรือ `[Claude 3.7 Sonnet]` คลิกเพื่อสลับโมเดลได้ทันทีโดยไม่ต้องเข้าหน้า Settings ลึกๆ
* **Progress Pill**: แสดงแถบหลอดสีเขียว-ฟ้าเรืองแสง พร้อมตัวเลขเปอร์เซ็นต์และสัดส่วน `(แปลแล้ว / ทั้งหมด)`
* **Auto-Save & Fast Save**: ปุ่มเซฟสถานะ และไฟเขียวกะพริบแจ้งเตือนเมื่อระบบเซฟเบื้องหลังเสร็จ

### 📋 โซนที่ 2: Navigation Grid (ตารางข้อมูลฝั่งซ้าย)
* **แถบตัวเลขบรรทัดแบบเรียบหรู**: รองรับการคลิกลากคลุมแถวต่อเนื่อง (Drag-selection)
* **Status Badges (Pills)**:
  - 🟢 `แปลแล้ว` (พื้นหลังเขียวอ่อน ตัวอักษรสีมินต์)
  - ⚪ `ว่าง / ยังไม่แปล` (สีเทากลืนกับตาราง)
  - 🇨🇳 `จีนหลุด` (ไฮไลท์สีพีชอมส้ม พร้อมขึ้นต้นคำเตือน)
  - 🔴 `QA Error` (สีแดงเข้มแจ้งเตือนคำศัพท์ไม่ตรง)
* **Floating Selection Action Bar**:
  - เมนูลอยตัวสไตล์ Capsule โค้งมน ลอยขึ้นมาเหนือตารางเมื่อเลือกมากกว่า 1 แถว มีปุ่ม:
    `[ ⚡ แปล AI (Ctrl+T) ]` `[ 🇨🇳 ล้างจีน ]` `[ 🧹 ล้างคำแปล ]` `[ 🗑️ ลบแถว (Shift+Del) ]`

### ✍️ โซนที่ 3: Translation Workbench (แท่นแปลอัจฉริยะฝั่งขวา)
1. **Source Text Card (การ์ดข้อความต้นฉบับ)**:
   - ฟอนต์ขนาดใหญ่ สบายตา (Sarabun / Segoe UI ขนาด 14-15px)
   - ตรวจจับคำใน Glossary แล้วขีดเส้นใต้สีเรืองแสง
   - **Quick Glossary Chips**: ใต้การ์ดจะมีป้ายชื่อศัพท์ เช่น `[🗡️ Ancient Blade ➔ ดาบโบราณ +]` เมื่อคลิกที่ปุ่ม `+` คำว่า "ดาบโบราณ" จะถูกพิมพ์แทรกลงในช่องคำแปลทันทีโดยไม่ต้องพิมพ์เอง!
2. **Translation Editor (กล่องคำแปลภาษาไทย)**:
   - กรอบโฟกัสเรืองแสงสีเขียวอ่อนเวลาพิมพ์
   - แสดงตัวเลขนับจำนวนตัวอักษร และสถานะ Auto-save แบบเรียลไทม์
   - ปุ่มหลัก **`[ ✓ ยืนยัน & แถวถัดไป (Enter) ]`** สีเขียวโดดเด่น
3. **AI Copilot Suggestions Deck (แท่นคำแปลปัญญาประดิษฐ์)**:
   - นำเสนอคำแปลเป็น 3 การ์ด/แท็บ:
     - **สไตล์ที่ 1 (`Ctrl+1`)**: ภาษาเกม / เป็นธรรมชาติ (ค่าแนะนำ)
     - **สไตล์ที่ 2 (`Ctrl+2`)**: ทางการ / ภาษาเควสต์
     - **สไตล์ที่ 3 (`Ctrl+3`)**: สบายๆ / บทสนทนาทั่วไป
   - กดปุ่มลัดเพียงปุ่มเดียว คำแปลจะกระโดดเข้าไปในช่อง Editor และกด `Enter` เพื่อจบงานแถวนั้นทันที

## 5. แผนผังทางลัดคีย์บอร์ด (Power-User Keyboard Flow)

```
[ เลือกแถว / ตาราง ]
        │
        ├──► กด [ Ctrl+T ]       ──► AI แปลประโยคปัจจุบันทันที
        ├──► กด [ Ctrl+1/2/3 ]   ──► เลือกสไตล์คำแปลที่ AI แนะนำลงช่องพิมพ์
        ├──► กด [ Enter ]        ──► ยืนยันคำแปล และเลื่อนเคอร์เซอร์ไปแถวถัดไปอัตโนมัติ
        ├──► กด [ Shift+Delete ] ──► ลบบรรทัดออกจากไฟล์ (Batch/Single)
        └──► กด [ Backspace ]    ──► ล้างคำแปลแถวที่เลือก
```
