# ⚡ Autonomous POC Fast-Track Guide (โหมดลุยอัตโนมัติขั้นตอน 1-3)

> **คู่มือสถาปัตยกรรมและโปรโตคอล**: การออกแบบระบบ Auto-Pilot ของ AI Helper สำหรับขั้นตอน 1 ถึง 3 เพื่อให้ผู้ใช้สามารถทดสอบภาษาไทยในเกมจริง (Proof of Concept) ได้ทันทีโดยไม่ต้องคอยยืนยันทีละขั้นตอน

---

## 1. ที่มาและปัญหาเดิม (The Problem & Motivation)

ในการทำ Mod แปลภาษาเกมแบบดั้งเดิมผ่าน AI Consultant:
1. **เกิดความล่าช้าจาก Friction**: ผู้ใช้ต้องคอยพิมพ์คำสั่งยืนยันทีละสเต็ป เช่น:
   - รอ AI สรุปขั้นตอนที่ 1 $\rightarrow$ ผู้ใช้ตอบ "ตกลงทำขั้น 2"
   - รอ AI เขียนสคริปต์สกัด $\rightarrow$ ผู้ใช้ตอบ "ตกลงทำขั้น 3"
2. **ความเหนื่อยล้าของผู้ใช้ (User Fatigue)**: สำหรับเอนจินยอดนิยมที่มีโครงสร้างชัดเจน (เช่น Unity TextMeshPro, Unreal Engine `.locres`, Ren'Py, RPG Maker หรือเอนจินที่มี GameBridge รองรับอยู่แล้ว) การหยุดถามทีละสเต็ปเป็นเพียงขั้นตอนเอกสารที่ซ้ำซ้อน
3. **เป้าหมายที่แท้จริงของผู้ใช้**: ผู้ใช้ต้องการทราบคำตอบเดียวให้เร็วที่สุดคือ **"เกมนี้แสดงผลภาษาไทยได้จริงไหม? สระลอยหรือไม่? ฟอนต์ขึ้นเป็นเต้าหู้ไหม?"**

ด้วยเหตุนี้ ระบบ **Autonomous POC Fast-Track (⚡ Auto-Pilot ขั้นตอน 1-3)** จึงถูกออกแบบมาเพื่อให้ AI ดำเนินการ **ขั้นตอน 1 $\rightarrow$ ขั้นตอน 2 $\rightarrow$ ขั้นตอน 3 ติดต่อกันในลูปเดียวอย่างปลอดภัย** จนกระทั่งแพตช์หน้าเมนูหลักสำเร็จ แล้วจึงหยุดรอผู้ใช้เปิดเกมทดสอบที่ **POC Gate**

## 2. Confidence Assessment Matrix (เกณฑ์ประเมินความมั่นใจของ AI)

ระบบกำหนดให้ AI ประเมินคะแนนความมั่นใจ (Confidence Score) ในขั้นตอนที่ 1.4 ก่อนตัดสินใจว่าจะเปิด Auto-Pilot หรือจะหยุดปรึกษาผู้ใช้:

```
                  ┌───────────────────────────────┐
                  │    Engine & Asset Scanner     │
                  │   (Engine, Format, Guides)    │
                  └──────────────┬────────────────┘
                                 │
                                 ▼
                  ┌───────────────────────────────┐
                  │   Confidence Score Evaluation │
                  └──────────────┬────────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       Score >= 80% (High)             Score < 80% (Low)
   ┌───────────────────────────┐   ┌───────────────────────────┐
   │ Autonomous Fast-Track ⚡  │   │ Classic Step-by-Step 🛑   │
   │  - Auto Step 1 (Backup)   │   │  - หยุดรายงานผลการสแกน    │
   │  - Auto Step 2 (Bridge)   │   │  - แจ้งความเสี่ยงให้ทราบ  │
   │  - Auto Step 3 (POC Menu) │   │  - รอผู้ใช้ยืนยันแนวทาง  │
   │  - Pause at Step 3.5 Gate │   └───────────────────────────┘
   └───────────────────────────┘
```

### ตารางเกณฑ์การให้คะแนนความมั่นใจ

| ปัจจัยที่ตรวจพบ | ระดับความมั่นใจ | คะแนน | การดำเนินการ |
| :--- | :---: | :---: | :--- |
| มี GameBridge ตรงรุ่น + คู่มือ Bible ตรงเกม + ฟอร์แมตมาตรฐาน | **Very High** | **95 - 100%** | **Auto-Pilot ทันที**: ลุยขั้นตอน 1-3 รวดเดียว |
| เอนจินที่คุ้นเคย (Unity, Unreal Engine, Ren'Py) + ฟอร์แมตปกติ (.locres, MonoBehaviour, json, csv) | **High** | **85 - 90%** | **Auto-Pilot ทันที**: ลุยขั้นตอน 1-3 รวดเดียว |
| เอนจินตรวจพบด้วย Heuristic (เช่น แพทเทิร์นไฟล์ตรง) + ไม่มี Anti-cheat ขวาง | **Moderate-High** | **80%** | **Auto-Pilot ทันที**: ลุยขั้นตอน 1-3 รวดเดียว |
| ฟอร์แมต proprietary ที่ไม่เคยมีในคลังความรู้ หรือมีการเข้ารหัสแบบปิด (Encrypted Archives) | **Low** | **50 - 70%** | **หยุดที่ขั้นตอนที่ 1**: วิเคราะห์เชิงลึกและปรึกษาผู้ใช้ |
| ตรวจพบระบบป้องกันเกม (Anti-Cheat, Denuvo, VMProtect, Integrity Check) | **Critical Risk** | **< 40%** | **หยุดทันที**: ห้ามแก้ไขไฟล์เด็ดขาด แจ้งความเสี่ยง |

## 3. รายละเอียดการทำงาน 3 ขั้นตอนแบบ Auto-Pilot (Steps 1 to 3)

### ขั้นตอนที่ 1: Extraction, Analysis & Failsafe (สำรวจและสร้างเกราะป้องกัน)
- [x] ตรวจสอบโฟลเดอร์เกมและโครงสร้าง Assets
- [x] **สร้าง `01_Original_Backup/` เสมอ**: คัดลอกไฟล์ต้นฉบับที่จะถูกแตะต้องเข้าไปเก็บไว้ และตั้งค่าแบบ Read-Only ป้องกันการทับ
- [x] ตรวจสอบระบบฟอนต์ (TTF/OTF, Sprite Font, BMFont, TextMeshPro SDF)
- [x] ประเมิน Confidence Score ($\ge 80\% \rightarrow$ เข้าสู่ขั้นตอนที่ 2 ทันทีโดยไม่ต้องรอคำสั่ง)

### ขั้นตอนที่ 2: Bridge & Tooling Architecture (สร้างสคริปต์เชื่อมต่อ)
- [x] ตรวจสอบว่ามี GameBridge ใน `tools/flagship/GameBridges/` หรือไม่
- [x] หากยังไม่มี ให้เขียนสคริปต์ Python ในโฟลเดอร์โปรเจกต์ `05_Scripts_and_Tools/`:
  - `extract_assets.py`: สำหรับคลายไฟล์/สกัดข้อความ
  - `repack_assets.py`: สำหรับแพ็คไฟล์กลับเข้าเกม
- [x] ทดสอบรันสกัดตัวอย่าง (Sample Run) เพื่อยืนยันว่าสคริปต์ทำงานได้จริงโดยไม่แครช
- [x] ส่งต่อข้อมูลเข้าสู่ขั้นตอนที่ 3 ทันทีโดยไม่ต้องหยุดรอ

### ขั้นตอนที่ 3: Proof of Concept — Menu & Font Test (พิสูจน์ผลลัพธ์ในเกมจริง)
- [x] สกัดข้อความเฉพาะส่วน **หน้าเมนูหลัก (Main Menu / Title Screen)** ประมาณ 5–15 บรรทัด
- [x] ส่งออกเป็นไฟล์มาตรฐาน TStudio CSV:
  ```csv
  key,source,translation,context,file_path
  UI_START_GAME,Start Game,เริ่มเกม,Main Menu,UI_Strings.json
  UI_OPTIONS,Options,ตั้งค่า,Main Menu,UI_Strings.json
  UI_QUIT,Quit,ออกจากเกม,Main Menu,UI_Strings.json
  ```
- [x] แปลข้อความเมนูหลักเป็นภาษาไทยด้วยคำกระชับ ได้ใจความ
- [x] **เตรียมฟอนต์ภาษาไทย (Font Pipeline)**:
  - ใช้ฟอนต์ PUA Standard (`0xF000`–`0xF89F`)
  - สำหรับ Unity: ใช้ `unity-native-font` MCP Server หรือสคริปต์สร้าง TMP Asset
  - ยกวรรณยุกต์ลอย +160 units ป้องกันสระ/วรรณยุกต์จมหรือทับตัวอักษร
- [x] **แพตช์ไฟล์เข้าเกมอย่างปลอดภัย**:
  - แบ็คอัพไฟล์ปลายทางเป็น `.orig` ในโฟลเดอร์เกมทุกครั้งก่อนเขียนทับ
  - นำไฟล์เมนูภาษาไทยและฟอนต์ที่แพ็คแล้วไปวางแทนที่
- [x] **Read-back Validation**: อ่านไฟล์ที่เพิ่งเขียนทับกลับมาเพื่อตรวจสอบว่าขนาดไฟล์ถูกต้องและไม่เสียหาย

## 4. The POC Gate Handoff (จุดหยุดเดียวเพื่อส่งมอบงานให้ผู้ใช้)

เมื่อขั้นตอนที่ 1, 2, และ 3 เสร็จสมบูรณ์แล้ว AI จะ **หยุดรอผู้ใช้เพียงจุดเดียว** คือ **POC Gate (ขั้นตอนที่ 3.5)** พร้อมส่งมอบรายงานที่เป็นมิตรและชัดเจน:

```markdown
══════════════════════════════════════════════════════
🎮 PROOF OF CONCEPT READY — เชิญเปิดเกมเพื่อทดสอบภาษาไทย
══════════════════════════════════════════════════════
ระบบได้ดำเนินการขั้นตอนที่ 1, 2 และ 3 ให้คุณโดยอัตโนมัติเรียบร้อยแล้ว:
  1. ✅ แบ็คอัพไฟล์ต้นฉบับไว้ที่: `01_Original_Backup/`
  2. ✅ เตรียมสคริปต์ Bridge และตรวจสอบความเข้ากันได้
  3. ✅ แปลและแพตช์หน้าเมนูหลัก (Main Menu) พร้อมติดตั้งฟอนต์ภาษาไทย

🕹️ วิธีทดสอบ:
  1. เปิดเกมผ่าน Steam หรือโฟลเดอร์เกม: `{Game_Path}/{Game_Exe}`
  2. สังเกตหน้าจอเมนูหลัก (Title Screen / Main Menu):
     • คำว่า "Start Game" ต้องแสดงเป็น "เริ่มเกม"
     • คำว่า "Options" ต้องแสดงเป็น "ตั้งค่า"
     • คำว่า "Quit" ต้องแสดงเป็น "ออกจากเกม"

🔍 รายการตรวจสอบฟอนต์ (Font Quality Checklist):
  [ ] สระและวรรณยุกต์แสดงผลถูกต้อง (ไม่มีสระลอย ไม่จม ไม่ทับตัวอักษร)
  [ ] ไม่ปรากฏเครื่องหมายกล่องสี่เหลี่ยมเต้าหู้ (□□□)
  [ ] ข้อความภาษาไทยไม่ล้นหรือหลุดออกจากกรอบ UI

💡 หากเกมมีปัญหาหรือต้องการย้อนกลับ (Rollback):
  • ไฟล์แบ็คอัพสำรองถูกสร้างไว้ข้างกันเป็นนามสกุล `.orig` เรียบร้อยแล้ว
  • สามารถกด Rollback ได้ทันทีจากปุ่มใน TStudio หรือแจ้งให้ผมกู้คืนให้ได้ครับ
══════════════════════════════════════════════════════
```

## 5. การทำงานร่วมกับ Unity Native Thai Font MCP Server

ในโปรเจกต์ที่เป็น Unity Engine ระบบ Fast-Track จะเชื่อมโยงกับโปรโตคอล `unity-native-font` โดยอัตโนมัติ:

1. **`scan_unity_font_references`**: สแกนหา PathID ของ TextMeshPro FontAsset ใน `resources.assets` หรือ `sharedassets0.assets`
2. **`build_thai_subset`**: ดึงชุดอักขระไทยที่จำเป็นจาก TStudio CSV เพื่อทำ Font Atlas ขนาดเล็ก ไม่เปลืองแรม
3. **`tune_thai_tone_marks`**: ปรับค่า vertical offset +160 units ป้องกันสระลอย
4. **`transplant_textmeshpro_font`**: ฝัง FontAsset ภาษาไทยเข้าไฟล์เกมอย่างปลอดภัยโดยไม่ต้องผ่าน Unity Editor

## 6. กฎเหล็กความปลอดภัย 4 ประการ (Safety Invariants)

| กฎข้อที่ | ชื่อกฎ | ข้อกำหนด |
| :---: | :--- | :--- |
| **1** | **Core Tool Immutability** | AI **ห้ามแก้ไข** ไฟล์ระบบหลักของ THub/TStudio (`trun_app.py`, `tstudio_app.py`, `tstudio_core.py`, `file_converter.py`) อย่างเด็ดขาด โค้ดใหม่ทั้งหมดต้องอยู่ใน `GameBridges/` หรือ `05_Scripts_and_Tools/` ของโปรเจกต์เท่านั้น |
| **2** | **Immutable Original Backup** | ต้องคัดลอกไฟล์ต้นฉบับเข้า `01_Original_Backup/` ก่อนที่จะเขียนไฟล์ใดๆ และห้ามเขียนทับหรือลบโฟลเดอร์นี้ตลอดชีพโปรเจกต์ |
| **3** | **Single-Gate Verification** | ห้ามข้ามขั้นตอนที่ 3 ไปทำ Mass Translation (ขั้นตอนที่ 4-6) จนกว่าผู้ใช้จะเปิดเกมและกดยืนยันว่าหน้าเมนูแสดงผลไทยได้สวยงาม 100% |
| **4** | **In-place `.orig` Failsafe** | ทุกไฟล์ในโฟลเดอร์เกมที่ถูกแพตช์ ต้องมีคู่แฝด `.orig` อยู่ข้างกันเสมอ เพื่อให้ผู้ใช้สามารถดับเบิลคลิกกู้คืนได้เองแม้ปิดโปรแกรมไปแล้ว |

## 7. สรุปผลประโยชน์ต่อผู้ใช้และทีมงาน

1. **ลดจำนวนการคลิกและการยืนยันลงถึง 66%**: จากเดิมที่ต้องกดยืนยัน 3 ครั้ง (ขั้นตอน 1, 2, 3) เหลือเพียงการเปิดเกมเช็คเพียงครั้งเดียว
2. **รู้ผลความพร้อมของเกมภายใน 1–2 นาที**: ผู้ใช้ได้เห็นฟอนต์ไทยจริงในเกมแทบจะทันทีหลังเริ่มโปรเจกต์
3. **ป้องกันบัคฟอนต์ตั้งแต่ต้นน้ำ**: หากฟอนต์มีปัญหาสระลอยหรือเต้าหู้ จะได้รับการแก้ไขให้เสร็จสิ้นในเมนูหลัก ก่อนที่จะไปเสียเวลาแปลบทสนทนาทั้งเกม
