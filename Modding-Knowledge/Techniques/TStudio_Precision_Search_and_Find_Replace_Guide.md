# คู่มือระบบค้นหาแม่นยำสูงและการแทนที่ข้อความใน TStudio (TStudio Precision Search & Find-Replace Guide)

คู่มือนี้อธิบายระบบการค้นหาข้อความ (Search & Filter) และการแทนที่คำแปล (Find & Replace) ของ **TStudio (Translation Studio)** ที่ได้รับการพัฒนาเพื่อแก้ปัญหาการค้นหาคำสั้นๆ เช่น ตัวอักษรเดี่ยว `e` ที่เดิมทีจะค้นหาแบบ Substring ทั่วไป ทำให้ได้ผลลัพธ์ครอบคลุมคำนับหมื่นคำ (`enter`, `the`, `equipment`, `#str_key_enter`) แทนที่จะเจอเฉพาะข้อความที่เป็น `e` ตัวเดียวล้วนๆ

---

## 1. ปัญหาเดิมและผลกระทบ (Problem Statement)

- **Substring Matching แบบเดิม**: `FilterProxy.filterAcceptsRow` เช็ค `query in text.lower()` ในทุกคอลัมน์ (`id`, `source`, `trans`, `tag`)
- **ผลกระทบ**: 
  - เมื่อพิมพ์ค้นหา `e` ตัวโปรแกรมจะตรวจพบตัว `e` ใน ID (เช่น `#str_key_...`), ในคำว่า `the`, `enter`, `enemy`, `equipment`, `game`, `escape` ฯลฯ ทำให้ผลลัพธ์แสดงเกือบทุกแถวในเกม (99.9% ของตาราง)
  - ผู้แปลไม่สามารถค้นหา Key สั้นๆ หรือตัวอักษรเดี่ยวๆ ที่เป็นปุ่มคำสั่งในเกม เช่น ปุ่ม `E` สำหรับกด Interact/โต้ตอบ ได้เลย

## 2. ฟังก์ชันโหมดค้นหาใหม่ (New Search Modes)

TStudio เพิ่มแถบปุ่มตัวเลือก 4 รูปแบบ ติดไว้ด้านขวาของช่องค้นหาด่วน พร้อมคีย์ลัดและ Smart Syntax:

```
[ 🔍 ค้นหา (กด [=] หรือพิมพ์ =e เพื่อหา 'e' ตัวเดียว)... ] [Aa] [W] [=] [.*]
```

| ปุ่ม | โหมดการทำงาน | คีย์ลัด | Smart Syntax | ตัวอย่างการทำงาน |
| :---: | :--- | :---: | :---: | :--- |
| **Aa** | **Match Case**<br>(ตรงตามตัวพิมพ์ใหญ่-เล็ก) | `Alt+C` | - | ค้นหา `e` จะเจอเฉพาะ `e` ตัวเล็ก **ไม่เจอ** `E` ตัวใหญ่ |
| **W** | **Match Whole Word / Lone Marks**<br>(ตรงทั้งคำ / สระ-วรรณยุกต์เดี่ยวๆ) | `Alt+W` | `"e"`<br>`"ำ"`<br>`"่"` | - **ภาษาอังกฤษ:** ค้นหา `e` จะเจอ `Press e to interact` แต่ **ไม่เจอ** `the`, `enter`<br>- **ภาษาไทย (สระ/วรรณยุกต์ลอย):** ค้นหา `"ำ"` หรือ `"่"` จะเจอเฉพาะ **สระลอย / วรรณยุกต์เดี่ยวๆ** เช่น `กด ่ เพื่อเปิด` หรือ `ปุ่ม [่]` หรือ ` ำ ` โดย **ไม่ปน** กับคำปกติอย่าง `ทำ`, `ที่`, `เล่น` |
| **=** | **Exact Match**<br>(ตรงทั้งประโยคเป๊ะๆ) | `Alt+E` | `=e`<br>`=ำ`<br>`=่` | ค้นหาแถวที่ข้อความทั้งเซลล์มีแค่ตัวอักษรนั้นโดดๆ เท่านั้น รองรับทั้งตัวอักษรภาษาอังกฤษ และสระ/วรรณยุกต์เดี่ยวๆ (เช่น `=e`, `=ำ`, `=่`) |
| **.\*** | **Regular Expression**<br>(นิพจน์เรกูลาร์) | `Alt+R` | `/^e$/` | รองรับ Pattern เช่น `^e$`, `\b[eE]\b`, `(?<![ก-ฮ])่` |

## 3. วิธีการใช้งานสำหรับนักแปล (Usage Guide)

### วิธีที่ 1: ค้นหาข้อความที่เป็นตัวอักษรเดี่ยวทั้งเซลล์ (Exact Match เช่น `=e`, `=ำ`, `=่`)
- **กดปุ่ม `=`** (หรือกดคีย์ลัด `Alt+E`): ช่องค้นหาจะเปิดโหมด Exact Match ทันที แล้วพิมพ์ `e` หรือ `ำ` หรือ `่`
- **หรือพิมพ์ `=e` / `=ำ` / `=่` ลงในช่องค้นหาตรงๆ**: โปรแกรมจะสลับเข้าสู่โหมด Exact Match ให้อัตโนมัติ
- **ผลลัพธ์**: จะพบเฉพาะแถวที่ Source Text หรือ Translation หรือ ID เป็นตัวอักษรนั้นโดดๆ ทั้งช่อง (ระบบทำ NFC Normalization และขจัด Invisible Spacing ให้อัตโนมัติ)

### วิธีที่ 2: ค้นหาคำภาษาอังกฤษเดี่ยวๆ ในประโยค (Whole Word เช่น `"e"`)
- **กดปุ่ม `W`** (หรือกดคีย์ลัด `Alt+W`): เปิดโหมด Whole Word แล้วพิมพ์ `e` (หรือพิมพ์ `"e"`)
- **ผลลัพธ์**: จะพบประโยคเช่น `Press e to open door` แต่ **จะไม่พบ** `the`, `enemy`, `enter`

### วิธีที่ 3: ค้นหาสระลอย / วรรณยุกต์เดี่ยวๆ ในภาษาไทย (Lone / Floating Marks เช่น `"ำ"`, `"่"`)
- **กดปุ่ม `W`** (หรือกดคีย์ลัด `Alt+W`) แล้วพิมพ์ `ำ` หรือ `่`
- **หรือพิมพ์ `"ำ"` หรือ `"่"` (ใส่เครื่องหมายคำพูด)** ในช่องค้นหาตรงๆ
- **กลไกอัจฉริยะ (Smart Diacritic Isolation):**
  - ในภาษาไทย สระและวรรณยุกต์บน-ล่าง (`ำ`, `่`, `้`, `๊`, `๋`, `์`, `ิ`, `ี`, `ึ`, `ื`, `ุ`, `ู`, `ั`, `็`) ปกติจะประสมติดกับพยัญชนะต้น เช่น `ทำ`, `ที่`, `เล่น`
  - หากค้นหาแบบปกติ ตัวอักษร `่` จะไปตรงกับคำเกือบทุกคำในภาษาไทย (หลายพันแถว) ทำให้นักแปลหาสระที่พิมพ์หลุดไม่เจอ
  - เมื่อเปิดโหมด `[W]` หรือพิมพ์ `"ำ"` / `"่"` ระบบจะตรวจจับทันทีว่าเป็น **Thai Dependent Mark** และใช้ Regex ค้นหาเฉพาะจุดที่เป็น **สระลอย / วรรณยุกต์เดี่ยวๆ** ที่ไม่ได้ประสมติดกับพยัญชนะต้น เช่น:
    - `ข้อความ ่ ลอย` (มีเว้นวรรคคั่น)
    - `กด [่] เพื่อเปิด` หรือ `กด (ำ) ทดสอบ` (อยู่ในวงเล็บ/เครื่องหมาย)
    - `่ เริ่มต้นประโยค` (หลุดมาต้นประโยค)
    - `เ่ สระหน้าตามด้วยไม้เอก` (วางตำแหน่งผิด)
    - **โดยจะไม่ดึงคำภาษาไทยปกติอย่าง `ทำ`, `น้ำ`, `ที่นี่`, `เล่นต่อ`, `เริ่มต้น` ขึ้นมาเลย 100%!**

## 4. ระบบค้นหาและแทนที่ข้อความ (Find & Replace Dialog)

กดคีย์ลัด `Ctrl+H` บนหน้าต่างหลัก TStudio:
- เพิ่ม Checkbox ตัวเลือก 3 ตัว:
  1. `Aa ตรงตัวพิมพ์ (Case)`
  2. `W ตรงทั้งคำ (Whole Word)`
  3. `= ตรงทั้งประโยค (Exact)`
- ช่วยให้สามารถแทนที่คำสั้นๆ ทั่วทั้งไฟล์ได้อย่างปลอดภัย 100% โดยไม่ไปกระทบคำอื่นๆ เช่น:
  - ต้องการแทนที่คำแปลของปุ่ม `E` ให้เป็น `กด E` โดยไม่ทำให้คำว่า `Enter` กลายเป็น `กด Enternter`

## 5. สถาปัตยกรรมทางเทคนิค (Technical Architecture)

### 1. `FilterProxy` ใน `tstudio_app.py`
```python
def set_search(self, text, match_case=False, match_whole_word=False, match_exact=False, match_regex=False):
    # รองรับ Smart Syntax
    if query.startswith('=') and len(query) > 1:
        self.match_exact = True
        query = query[1:].strip()
    elif query.startswith('"') and query.endswith('"') and len(query) >= 2:
        self.match_whole_word = True
        query = query[1:-1]
```

### 2. Regular Expression Word Boundary สำหรับภาษาไทยและสากล
เนื่องจาก `\b` ของ regex ปกติอาจไม่ครอบคลุมตัวอักษรภาษาไทย ระบบจึงใช้ Boundary Regex พิเศษ:
```python
pat = r'(?<![A-Za-z0-9_ก-๙])' + re.escape(query) + r'(?![A-Za-z0-9_ก-๙])'
```
ช่วยให้การค้นหาคำเดี่ยวๆ ทำงานได้อย่างถูกต้องทั้งภาษาอังกฤษและภาษาไทย
