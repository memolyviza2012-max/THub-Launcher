# คู่มือระบบจัดการการตั้งค่าโปรเจกต์ และเครื่องยนต์สแกนคลังเกมในเครื่อง (THub Project Settings & Game Library Scanner)

## 1. บทนำ (Overview)
คู่มือฉบับนี้อธิบายสถาปัตยกรรมและวิธีการใช้งานระบบตั้งค่าโปรเจกต์จากการ์ดเกมโดยตรง และระบบตั้งค่าส่วนกลางของ THub Launcher 2.0 พร้อมเครื่องยนต์สแกนคลังเกมในเครื่องคอมพิวเตอร์อัตโนมัติ (Automated Game Library Scanner)

---

## 2. ระบบแก้ไขการตั้งค่าโปรเจกต์จากการ์ดเกม (Project Settings on Card)

ผู้ใช้สามารถเข้าถึงหน้าต่างตั้งค่าโปรเจกต์ได้โดย:
1. คลิกที่ปุ่มตัวเลือก `[⋮]` หรือคลิกขวาที่การ์ดเกมใดๆ บนหน้า Dashboard
2. เลือกเมนู **`🛠️ ตั้งค่าโปรเจกต์ (Project Settings)...`**

### ฟิลด์ที่รองรับการปรับแต่ง:
- **ชื่อโปรเจกต์ / เกม (`name`)**: ชื่อที่แสดงบนการ์ดและในระบบ
- **โฟลเดอร์ Workspace (`path`)**: ตำแหน่งจัดเก็บไฟล์ม็อดและโฟลเดอร์มาตรฐาน 01–06 (พร้อมปุ่ม `📂 เลือก`)
- **ตำแหน่งติดตั้งเกม (`game_dir`)**: ตำแหน่งที่เกมติดตั้งอยู่จริงบนเครื่อง (พร้อมปุ่ม `📂 เลือก` และปุ่ม `🔍 สแกนหาเกม`)
- **ตำแหน่งโฟลเดอร์เครื่องมือ (`tool_dir`)**: ตำแหน่งชุดเครื่องมือเฉพาะโปรเจกต์ หรือกดปุ่ม `🔄 ค่าเริ่มต้น` เพื่อใช้ `E:\Mod_Workspace\Tool`
- **Game Engine**: เลือกหรือพิมพ์ Engine เองได้ พร้อมกล่องตัวอย่าง Badge และสีแสดงผลแบบ Real-time
- **สถานะโปรเจกต์ (`status`)**: กำลังแปล (In Progress), แปลเสร็จแล้ว (Completed), พร้อมใช้งาน (Imported)
- **ภาษาต้นฉบับ / ภาษาเป้าหมาย**: Source/Target Language
- **ผู้แปล / ผู้มีส่วนร่วม / บันทึกย่อ**: Author, Contributors, Notes

### กลไกการซิงก์ข้อมูล (Two-Way Synchronization):
เมื่อกดปุ่ม `💾 บันทึกการตั้งค่า`:
1. ระบบจะอัปเดตข้อมูลใน `hub_config.json` ผ่าน `ProjectService.update_project()`
2. หากในโฟลเดอร์ Workspace มีไฟล์ `thub_project.json` อยู่ ระบบจะทำการอัปเดตฟิลด์ทั้งหมดให้ตรงกันทันที
3. ส่ง Signal แจ้งเตือน Dashboard ให้ทำการรีเฟรชการ์ด แสดงชื่อใหม่ Badge ใหม่ และสถานะใหม่ทันทีโดยไม่ต้องรีสตาร์ตโปรแกรม

## 3. ระบบตั้งค่าส่วนกลางของ THub (Global THub Settings)

เข้าถึงได้จาก:
- ปุ่ม **`⚙️ ตั้งค่า`** ที่ Header Bar ด้านบน
- เมนู **`⚙️ การตั้งค่าระบบ`** ใน Sidebar ด้านซ้าย

### 3.1 ตำแหน่งโฟลเดอร์หลัก (Paths & Workspaces)
- **ตำแหน่งโฟลเดอร์โปรเจกต์ถาวร (`default_workspace_dir`)**: ค่าเริ่มต้นคือ `E:\Mod_Workspace` เมื่อผู้ใช้สร้างโปรเจกต์ใหม่ ระบบจะเติมพาธ `{default_workspace_dir}\{GameName}` ให้อัตโนมัติ
- **ตำแหน่งเครื่องมือถาวร (`default_tools_dir`)**: ค่าเริ่มต้นคือ `E:\Mod_Workspace\Tool` ใช้เป็นตำแหน่งอ้างอิงเครื่องมือส่วนกลาง

### 3.2 คลังเกมและตัวสแกน (Game Libraries & Scanner)
- แสดงรายการโฟลเดอร์คลังเกมที่ระบบตรวจพบอัตโนมัติจาก Steam (`libraryfolders.vdf`)
- รองรับการเพิ่มโฟลเดอร์คลังเกมที่กำหนดเอง (Custom Game Libraries) เช่น `D:\Games`, `G:\EpicGames` ฯลฯ
- แสดงสถานะจำนวนเกมที่ติดตั้งในเครื่อง พร้อมปุ่ม `🔄 สแกนใหม่`

### 3.3 ทั่วไป (General)
- กำหนดชื่อผู้แปลเริ่มต้น (`default_author`)
- เลือกธีมสี (`active_theme`): Obsidian, Monokai, Cyberpunk, Midnight Blue
- ภาษาของระบบ (`app_lang`): ไทย / English
- สวิตช์เปิด/ปิดการดาวน์โหลดภาพปก 16:9 จาก Steam อัตโนมัติ (`steam_auto_capsule`)

## 4. เครื่องยนต์สแกนคลังเกมในเครื่อง (`core/game_scanner.py`)

`GameScanner` ทำงานแบบ High-performance In-Memory Caching:
1. **Steam Auto-Detection**:
   - ค้นหาและถอดรหัสไฟล์ `libraryfolders.vdf` จากทุกเส้นทางมาตรฐานของ Steam
   - ค้นหาไดเรกทอรี `SteamLibrary\steamapps\common` ในทุกไดรฟ์ของคอมพิวเตอร์ (`C:`, `D:`, `E:`, `F:`, ฯลฯ)
2. **System & Custom Store Folders**:
   - ค้นหาโฟลเดอร์ `XboxGames`, `GOG Games`, `Epic Games`, `Games`
   - รวมโฟลเดอร์ที่ผู้ใช้เพิ่มไว้ใน `game_library_paths`
3. **Smart Matching Engine**:
   - ใช้อัลกอริทึม Token Overlap + Substring Matching + Exact Matching
   - ขณะพิมพ์ชื่อเกมในหน้า **สร้างโปรเจกต์ใหม่ (`ProjectWizardDialogQt`)**:
     - Workspace จะถูกเติมอัตโนมัติเป็น `E:\Mod_Workspace\{Clean_Game_Name}`
     - หากพบโฟลเดอร์เกมติดตั้งอยู่ในเครื่อง ระบบจะแสดงป้ายแนะนำ:
       `🎮 ตรวจพบในเครื่อง: The Witcher 3 (Steam) — คลิกเพื่อใช้โฟลเดอร์นี้`
     - เมื่อคลิก ระบบจะกรอกช่องตำแหน่งเกมและตรวจจับ Engine ให้เสร็จสรรพในคลิกเดียว!
